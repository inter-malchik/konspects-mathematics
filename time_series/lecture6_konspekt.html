§1. Мотивация и определения (сл. 3–6)

1.1. Зачем считать пересечения уровней? (сл. 3)

Вопрос-якорь: как часто процесс будет превышать критический уровень $u$? Надёжность — вибрация подшипника: число превышений порога усталости; телеметрия — пики тока/напряжения в бортовых системах; медицина — аномальные пики ЭКГ, апноэ-события; климат — дни с температурой выше нормы. Связь с курсом: Лекция 5 — спектр процесса определяет частоту пересечений; Лекция 7 — EVT описывает распределение максимумов (сл. 3).

Из записи лекции [01:11–06:32]

Случайный процесс называется случайным потому, что ведёт себя недетерминированно; наблюдаем мы одну траекторию — одну реализацию, тогда как полное описание содержит, как правило, бесконечно много возможных траекторий (аналогия: генеральная совокупность и выборка). Оценивать траекторию можно по тому, как часто процесс выходит за некоторую границу — критический уровень. Примеры: подшипник вибрирует по природе своей, у вибрации есть порог усталости — чем больше превышений уровня, тем ближе разрушение детали, и по частоте превышений судят о состоянии; бортовая телеметрия — скачки тока и напряжения как признак нештатной ситуации; медицина — аномалии на ЭКГ проявляются всплесками, выходами за допустимый уровень, а кардиограмму можно рассматривать как случайную функцию. Во всех примерах вопрос один: как часто процесс пересекает заданный уровень $u$. На рисунке при высоком уровне процесс его ни разу не пересекает; опустив уровень, получаем несколько пересечений.

На пальцах

Пересечения уровня — «счётчик тревог»: мы не описываем всю траекторию, а ставим порог и считаем, сколько раз за час стрелка вышла за красную черту. Это самый дешёвый датчик состояния системы (Лекция 5: достаточно простого счётчика), а теория этой лекции говорит, каким это число должно быть у «здорового» процесса — чтобы заметить, когда оно перестало таким быть.

1.2. Определения: восходящее и нисходящее пересечение, выброс (сл. 4)

Положительное (восходящее) пересечение, upcrossing: точка $t_0$, где $X(t_0)=u$ и $\dot X(t_0)\gt0$ (процесс пересекает уровень снизу вверх). Отрицательное (нисходящее), downcrossing: $X(t_0)=u$ и $\dot X(t_0)\lt0$. Выброс (excursion): промежуток $[t_1,t_2]$, где $X(t)\gt u$ для всех $t\in(t_1,t_2)$; каждый выброс начинается с положительного пересечения (сл. 4).

Рисунок (сл. 4). Синяя осциллирующая траектория $X(t)$ на 0–300 отсчётов, горизонтальный пунктир уровня $u$; красные точки — восходящие пересечения, зелёные — нисходящие; закрашенные участки над пунктиром — выбросы.
Из записи лекции [06:32–10:24]

Когда процесс пересекает уровень снизу вверх — положительное, или восходящее, пересечение (upcrossing): в момент $t_0$ значение процесса равно $u$, а производная в этот момент больше нуля — процесс растёт. Обратное — отрицательное, нисходящее пересечение (downcrossing): значение равно $u$, производная отрицательна. По знаку производной определяется направление пересечения. Промежуток, на котором процесс находится выше уровня, — выброс (excursion): положительный выброс начинается положительным пересечением и заканчивается отрицательным; отрицательный (процесс ниже уровня) — наоборот. Пересечение — момент времени, выброс — интервал: у него есть длина, высота, площадь, и все они измеримы и могут представлять интерес.

На пальцах

Пересечение — «событие», выброс — «эпизод». Производная нужна только для того, чтобы отличить «вход» в опасную зону от «выхода»: считать логично входы (восходящие пересечения) — столько же раз будет и выходов, если процесс возвращается. У каждого эпизода три размера: как долго ($L$), как высоко ($H$), как много суммарно ($S$) — §5.

1.3. Частота пересечений: эмпирическая оценка (сл. 5)

Пусть $N^+(u,T)$ — число восходящих пересечений уровня $u$ за время $T$. Эмпирическая оценка частоты: $$\hat\nu^+(u)=\frac{N^+(u,T)}{T};$$ $N^+(u,T)$ подсчитывается по знаковым переходам: $\operatorname{sign}(X(t_i)-u)$ меняется с $-$ на $+$. При $u=0$ $\hat\nu^+(0)$ максимальна; при $u\uparrow$ $\hat\nu^+(u)\downarrow$ — высокие уровни реже. Реализация: numpy.diff(np.sign(x - u)). Свойство симметрии (гауссовский процесс): $\nu^+(u)=\nu^-(-u)$ при нулевом среднем (сл. 5).

Рисунок (сл. 5). Кривая $\hat\nu^+(u)$ по оси $u/\sigma$ от 0 до 3: максимум $\nu^+(0)$ при нуле, затем колоколообразный спад с подписью $\propto e^{-u^2/2\sigma^2}$; отмечено значение $\nu^+(\sigma)$ при $u/\sigma=1$.
Из записи лекции [10:24–15:55]

Прямой способ измерить: взять запись процесса длиной $T$, посчитать, сколько раз он пересёк уровень $u$ снизу вверх ($N^+$, плюс — положительные пересечения), и поделить на $T$ — эмпирическая частота положительных пересечений. Программно очень просто: вычитаем $u$ из всех значений дискретной реализации и смотрим на знак разности; каждая смена знака с минуса на плюс — положительное пересечение (лектор оговаривается «выброс» и поправляет: пересечение); в NumPy — одна строчка. На графике справа по горизонтали уровень, нормированный по СКО, по вертикали частота: нулевой уровень пересекается чаще всего, чем выше уровень, тем реже — высокие значения редки, «интуитивно понятно». Свойство гауссовского процесса с нулевым средним: положительные пересечения уровня $u$ так же часты, как отрицательные пересечения того же уровня — из симметрии; посчитанная величина характеризует и те и другие. Работает для любого симметричного распределения с нулевым средним; при ненулевом среднем свойство перестаёт работать.

На пальцах

Считаем «входы в зону выше $u$»: превращаем ряд в последовательность знаков «выше/ниже» и считаем переходы «ниже → выше». В ноутбуке лектора есть важная оговорка: np.diff(np.sign(x - u)) == 2 пропустит пересечение, если какая-то точка лежит ровно на уровне (знак 0), поэтому надёжнее np.sum((x[:-1] < u) & (x[1:] >= u)). Симметрия: у гауссовского процесса «выходы вверх через $+u$» и «выходы вниз через $-u$» — зеркальные события.

Вне слайдов

Уточнение записи слайда: $\nu^+(u)=\nu^-(-u)$ — частота восходящих пересечений уровня $u$ равна частоте нисходящих пересечений уровня $-u$; для стационарного процесса, кроме того, $\nu^+(u)=\nu^-(u)$ (что зашло вверх, то и вышло вниз), поэтому у симметричного процесса $\nu^+(u)=\nu^+(-u)$ — это и проверяет ноутбук (кривые $\hat\nu^+(+u)$ и $\hat\nu^+(-u)$ совпадают). Единицы $\hat\nu^+$ — пересечений на отсчёт (или в секунду при делении на $T$ в секундах).

1.4. Связь с производной процесса (сл. 6)

Ключевая идея: пересечение нуля процессом $X(t)$ эквивалентно смене знака $X(t)$. Гладкий (узкополосный) процесс: $|\dot X|$ мало → мало нулевых пересечений; зашумлённый (широкополосный): $|\dot X|$ велико → много. Вывод: дисперсия производной $\lambda_2=D[\dot X]$ управляет частотой пересечений нуля (сл. 6).

Рисунок (сл. 6). Два процесса по 300 отсчётов с одинаковой дисперсией: слева синий «узкополосный ($\varepsilon=0{,}2$), пересечений нуля 99» — плавные волны; справа красный «широкополосный ($\varepsilon=0{,}5$), пересечений нуля 224» — частая дрожь.
Из записи лекции [15:55–18:24]

От чего частота пересечений зависит теоретически: два процесса с одинаковой дисперсией, но разным поведением. Слева гладкий узкополосный — медленно поднимается и опускается, пересечений нуля мало; справа зашумлённый широкополосный — «дрожит», меняет знак чуть ли не на каждом отсчёте. Разница — в скорости изменения, то есть в производной: у гладкого процесса производная по модулю мала, у зашумлённого велика. Вывод: дисперсия производной — обозначим $\lambda_2$ — управляет частотой пересечения нуля; условно это «шероховатость» процесса: гладкий — маленькая $\lambda_2$ и мало пересечений, зашумлённый — большая $\lambda_2$ и много.

На пальцах

Два бегуна с одинаковым «размахом» дорожки: один идёт плавными длинными зигзагами, другой мечется — второй пересекает осевую линию в разы чаще. Размах — это $\lambda_0$ (дисперсия), «нервность» — $\lambda_2$ (дисперсия скорости). Формула Райса в §3 и скажет: частота пересечений нуля $\propto\sqrt{\lambda_2/\lambda_0}$.

2.1. Спектральные моменты λ₀, λ₁, λ₂ (сл. 7)

Определение через СПМ $S(\omega)$: $$\lambda_n=\int_0^{+\infty}\omega^n S(\omega)\,d\omega,\qquad n=0,1,2,$$ $S(\omega)$ — односторонняя спектральная плотность мощности.

Из записи лекции [18:24–21:38]

Формальный инструмент — спектральные моменты: числа, извлекаемые из спектральной плотности мощности: СПМ умножается на $\omega^n$ и интегрируется по всем частотам. При $n=0$ — просто площадь под спектром; по теореме (лектор называет её теоремой Парсеваля) интеграл от СПМ равен дисперсии процесса — не производной, а самого процесса. Первый момент — центр тяжести спектра, где сосредоточена основная энергия по частотам. Второй — «кривизна» спектра, его взвешенная среднеквадратичная ширина, и это как раз дисперсия производной. На рисунке площадь под кривой — $\lambda_0$, вертикальный пунктир — $\lambda_1$, ширина пика отражает $\lambda_2$ (стрелкой не показана).

На пальцах

Спектр — «распределение массы по частотам»: $\lambda_0$ — вся масса (дисперсия), $\lambda_1/\lambda_0$ — центр масс (типичная частота), $\lambda_2/\lambda_0$ — «момент инерции» (насколько масса разнесена к высоким частотам). Чем больше массы на высоких частотах, тем «нервнее» процесс, — отсюда $\lambda_2$ как дисперсия производной: дифференцирование умножает спектр на $\omega^2$.

Вне слайдов

$\lambda_0=D[X]$ — это теорема Винера–Хинчина при $\tau=0$ ($R(0)=\int S$); теорема Парсеваля — родственное тождество об энергии сигнала во времени и в частоте, лектор использует название как синоним. $\lambda_2=D[\dot X]=-R''(0)$: дифференцирование стационарного процесса умножает СПМ на $\omega^2$, поэтому спектр должен убывать быстрее $\omega^{-3}$, иначе $\lambda_2=\infty$ и процесс не дифференцируем (белый шум, ARMA в дискретном времени «как непрерывные» — см. п. 3.4).

2.4. Оценка спектральных моментов через ДПФ (сл. 10)

Реализуется через scipy.signal.periodogram. Замечание о единицах: если $f$ в Гц, $\lambda_n$ в Гц$^n\cdot$(ед. сигнала)$^2$; при переходе к угловым частотам $\omega=2\pi f$ (сл. 10).

По дискретным данным непрерывный интеграл заменяется суммой: $f_k$ — частоты дискретной сетки, $P$ — оценка СПМ по периодограмме, $\Delta f$ — шаг по частоте. В Python — scipy.signal.periodogram возвращает и частоты, и периодограмму, дальше три строчки суммирования. Важно следить за единицами: если частота в герцах, момент измеряется в герцах в степени $n$, умноженных на квадрат единиц сигнала (периодограмма — квадрат единиц сигнала); при переходе к угловым частотам не забыть домножить на $(2\pi)^n$.

На пальцах

Взвешенная сумма периодограммы — «интеграл прямоугольниками» по сетке частот. Единственная ловушка, на которой ноутбук лектора делает акцент: periodogram нормирован так, что $\sum P(f_k)\Delta f=\sigma^2$, поэтому шаг сетки берётся по $f$ ($\Delta f$), а частоты в весах — угловые ($\omega_k=2\pi f_k$); если умножить ещё и на $\Delta\omega=2\pi\Delta f$, получится $\lambda_0=2\pi\sigma^2$ — ошибка. Проверка корректности всегда одна: $\hat\lambda_0\approx\operatorname{Var}(x)$ (в ноутбуке и песочнице — $1{,}000$ для нормированных рядов).

Вне слайдов

Нулевой бин ($f=0$) отбрасывают или предварительно центрируют ряд — иначе среднее попадает в $\lambda_0$; при тренде — detrend (Лекция 5). Периодограмма несостоятельна, но взвешенные суммы по всем бинам усредняют её шум, поэтому $\hat\lambda_n$ устойчивы; для коротких рядов ($N\sim300$, солнечные пятна) разброс заметен — можно брать Уэлча. Формула слайда использует $f_k^n$; для угловых моментов (как в формуле Райса с $\omega$) — $\omega_k^n=(2\pi f_k)^n$; главное — одна и та же система единиц в $\lambda_0$ и $\lambda_2$: тогда $\sqrt{\lambda_2/\lambda_0}/(2\pi)$ даёт частоту в «1/отсчёт» при $f_s=1$.

§3. Формула Райса (сл. 11–14)

3.1. Формула Райса: идея вывода (сл. 11)

Два ключевых факта для стационарного гауссовского процесса: (1) пара $(X(t),\dot X(t))$ — совместно нормальная и некоррелированная (следует из дифференцирования стационарной КФ); (2) восходящее пересечение уровня $u$ — это событие $\{X(t)=u\}\cap\{\dot X(t)\gt0\}$. Интегральная формула: $$\nu^+(u)=\int_0^{+\infty}\dot x\,p(u,\dot x)\,d\dot x,$$ $p(u,\dot x)$ — совместная плотность $(X,\dot X)$ в точке $(u,\dot x)$; $\dot x$ — «скорость», с которой пересекается уровень (сл. 11).

Рисунок (сл. 11). Плоскость с осями $X$ (горизонталь) и $\dot X$ (вертикаль); пунктирные эллипсы — линии уровня совместной плотности $p(X,\dot X)$; красная вертикаль $X=u$; закрашенная область над ней подписана «$\dot X\gt0$», с указанием интеграла $\int_0^{+\infty}\dot x\,p\,d\dot x$; ниже — «$\dot X\lt0$».

Главная формула лекции — формула Райса. Стивен Райс вывел её в 1944–45 годах, более 70 лет назад, — аналитическую формулу для средней частоты пересечения уровня; «один из важнейших результатов теории случайных процессов». Ремарка: Райс работал в AT&T Bell Laboratories — исследовательском подразделении, которому мы обязаны Unix, языком C, радиоастрономией, мобильной связью и многим другим; хаб передовых исследований с середины XX века до 1990-х; Райс занимался фундаментальными исследованиями случайных процессов, не программированием.

Идея вывода. Первое: для стационарного гауссовского процесса пара «процесс и его производная» совместно нормальна и некоррелирована — не очевидно, но следует из дифференцирования стационарной корреляционной функции: производная в той же точке не коррелирована с самим процессом. Производная гауссовского процесса — тоже гауссовский процесс, поэтому совместное распределение двумерное нормальное: «гауссов колокольчик, который вращают, — получается шляпа»; на рисунке мы смотрим на неё сверху и видим линии уровня. Второе: восходящее пересечение — событие «процесс равен $u$ и одновременно производная положительна». На рисунке горизонталь — значение процесса, вертикаль — производная, «фазовый портрет»; красная вертикаль — уровень $u$. Уточнение лектора (41:38): рисунок «нарисован неправильно — ось должна была быть по-другому»: подпись «$\dot X\gt0$» стоит там, где производная положительна везде, если ноль по вертикали проведён иначе; смысл — закрашивается верхняя половина линии $X=u$.

На пальцах

Сколько раз в единицу времени процесс «проходит через дверь» $X=u$ снизу вверх? Вероятность оказаться у двери — $p(u,\dot x)$; но за единицу времени через дверь пройдут только те, кто движется вверх, и тем чаще, чем быстрее: быстрый процесс «пробегает» уровень много раз, медленный — редко. Поэтому под интегралом стоит скорость $\dot x$, умноженная на плотность, и интегрируем по положительным скоростям. Некоррелированность $X$ и $\dot X$ — как у синусоиды: в максимуме скорость нулевая, при нуле — максимальная, «сдвиг на четверть периода».

Вне слайдов

Формально это формула Райса в общем виде (для любого дифференцируемого стационарного процесса с совместной плотностью $p(x,\dot x)$); для гауссовского случая $X\sim\mathcal{N}(0,\lambda_0)$, $\dot X\sim\mathcal{N}(0,\lambda_2)$ независимы, и интеграл берётся явно: $\int_0^\infty\dot x\,\varphi_{\lambda_2}(\dot x)d\dot x=\sqrt{\lambda_2/2\pi}$, откуда результат сл. 12. Некоррелированность: $\mathbb{E}[X(t)\dot X(t)]=\tfrac12\frac{d}{dt}\mathbb{E}[X^2(t)]=0$ по стационарности. Источник: Rice S. O., Mathematical Analysis of Random Noise, Bell System Technical Journal, 1944 (ч. 1) и 1945 (ч. 2) — ссылки приведены в ноутбуке.

Средняя частота пересечений — математическое ожидание числа точек на красной линии, приведённое к единице времени: скорость изменения процесса, умноженная на вероятность оказаться в точке, проинтегрированная по всем положительным скоростям. Подставив нормальную плотность, получаем результат, в котором появляются нулевой и второй спектральные моменты. Первый множитель — $\frac1{2\pi}$ на корень из отношения моментов — средняя частота положительных пересечений нуля; он зависит только от «шероховатости» $\lambda_2$ относительно «амплитуды» $\lambda_0$. На пальцах

Два сомножителя — «темп» и «шанс»: темп $\nu^+(0)$ — сколько раз в единицу времени процесс качается через середину (для синусоиды частоты $f$ это ровно $f$), шанс $e^{-u^2/2\sigma^2}$ — насколько уровень $u$ далёк в единицах $\sigma$: на $1\sigma$ пересечений в $1{,}65$ раза меньше, чем через ноль, на $2\sigma$ — в $7{,}4$, на $3\sigma$ — в 90 раз. 3.3. Дисперсия числа пересечений (сл. 13)

Точная формула (Райс, 1945): $$\operatorname{Var}[N^+]=2\int_0^{T}(T-\tau)\big[p_2(u,u,\tau)-(\nu^+)^2\big]\,d\tau,$$ $p_2(u,u,\tau)$ — совместная плотность $(X(0),X(\tau))$ в точке $(u,u)$; на практике вычислительно сложно. Пуассоновское приближение (высокие $u$): $\operatorname{Var}[N^+]\approx\mathbb{E}[N^+]=\nu^+(u)\cdot T$; коэффициент вариации $\mathrm{CV}=\sqrt{\operatorname{Var}}/\mathbb{E}[N^+]\to1$ при $u\to\infty$. При высоких $u$ редкие превышения ведут себя как пуассоновский поток; при низких $u$ у узкополосного процесса $\mathrm{CV}\lt1$ — пересечения регулярнее пуассоновских (сл. 13).

Следующий вопрос — насколько средняя частота стабильна: разные реализации дают разное число пересечений, это нормально, вопрос — как сильно разброс. Во второй части работы (1945) Райс вывел и формулу дисперсии числа пересечений через совместную плотность значений процесса в моменты $0$ и $\tau$; формула точная, но требует двумерного распределения и численного интегрирования — напрямую её почти никто не использует. Вместо этого — пуассоновское приближение для высоких уровней: дисперсия примерно равна среднему; коэффициент вариации стремится к единице при росте уровня: редкие превышения ведут себя как пуассоновский поток, случайно и независимо. По правильному рисунку: обе кривые CV растут и сходятся к единице при больших $u$; при низких уровнях CV меньше единицы — пересечения чаще и регулярнее пуассоновских, особенно у узкополосного процесса, колебания которого почти периодичны (у чистой синусоиды число пересечений вообще детерминировано). Гистограммы числа пересечений при высоком уровне близки к нормальным, при низком — более сжатые.

Узкополосный процесс пересекает ноль «по расписанию» — раз в период, разброс числа пересечений крошечный; редкие превышения высокого уровня происходят «когда получится» — как звонки в колл-центр, пуассоновски: разброс равен среднему. Уточнение к сл. 13: к единице стремится именно индекс дисперсии $\operatorname{Var}/\mathbb{E}$ (что и означает «$\operatorname{Var}\approx\mathbb{E}$»); величина $\sqrt{\operatorname{Var}}/\mathbb{E}$ при редких событиях ведёт себя как $1/\sqrt{\mathbb{E}}$ и к единице не стремится.

§5. Характеристики выбросов (сл. 17–21)

5.1. Анатомия выброса: длина L и высота H (сл. 17)

Длина выброса $L$ (duration): время непрерывного пребывания процесса выше уровня $u$: $L=t_2-t_1$, $X(t)\gt u\ \forall t\in(t_1,t_2)$. Высота выброса $H$ (amplitude): превышение максимума над уровнем: $H=\max_{t\in[t_1,t_2]}X(t)-u$. Зависимость от уровня: $u\uparrow$ → выбросы реже и короче; $u\uparrow$ → выбросы выше (только самые большие «пробиваются»); $L$ и $H$ — случайные величины с нетривиальными распределениями (сл. 17).

Рисунок (сл. 17). «Характеристики выброса». Фрагмент траектории с пунктиром $u$; один выброс закрашен; горизонтальная стрелка вдоль уровня — длина $L$ от $t_1$ до $t_2$; вертикальная стрелка от уровня до максимума — высота $H$.

Формула Райса даёт частоту выбросов; теперь — характер каждого: как долго длится, как высоко поднимается. На рисунке один выброс с разметкой: процесс пересекает уровень снизу вверх в $t_1$ (положительное пересечение), сверху вниз в $t_2$ (лектор оговаривается «отрицательный выброс» и поправляет: пересечение); между ними где-то спрятан максимум. Длина — $t_2-t_1$, в тех же единицах, что время: секунды или, при дискретном времени, отсчёты. Высота — максимум процесса на интервале минус уровень: дополнительная высота над порогом, не абсолютное значение. Зависимость от $u$: выше уровень — выбросов меньше (следует из формулы Райса), каждый короче — до порога добираются только быстрые короткие пики, — и при этом выше, потому что до высокого уровня пробиваются только самые экстремальные события. $L$ и $H$ — случайные величины со своими распределениями.

5.4. Площадь выброса и теорема Слепяна (сл. 20)

Площадь выброса: $$S=\int_{\{t:\,X(t)\gt u\}}\big(X(t)-u\big)\,dt$$ — суммарное «превышение» процесса над уровнем за один выброс. Теорема Слепяна (огибающая): огибающая узкополосного гауссовского процесса $$R(t)=\sqrt{X^2(t)+\hat X^2(t)},$$ где $\hat X$ — преобразование Гильберта; следствие: пиковые значения выбросов не гауссовы — они распределены по Рэлею. Важно для практики: наивный гауссовский расчёт риска занижает вероятность высоких пиков (сл. 20).

Последняя характеристика — площадь: суммарное превышение за всё время выброса, интеграл. Теорема Слепяна касается огибающей узкополосного гауссовского процесса: огибающая строится из процесса $X$ и его преобразования Гильберта («аналог квадратурной компоненты») как корень из суммы квадратов. Теорема говорит: локальные пиковые значения огибающей — максимумы внутри выбросов — распределены не по Гауссу, а по Рэлею (то распределение, что на предыдущем слайде). Для инженерных расчётов важно: если рассчитывать вероятность экстремального пика «наивно», по хвосту нормального распределения, риск занижается — реальные пики тяжелее, чем предсказывает гауссовское приближение; это предпосылка к теории экстремальных значений, тема следующей лекции.

На пальцах

Огибающая — «линия, соединяющая гребни волн»: преобразование Гильберта достраивает к сигналу его сдвинутую на четверть периода копию, и $\sqrt{X^2+\hat X^2}$ — мгновенная амплитуда (в Лекции 5 так следили за амплитудой дефекта подшипника). Гребни распределены по Рэлею с масштабом $\sigma$ — проверено в песочнике (масштаб $1{,}00$ при $\sigma=1$). Почему «наивный расчёт занижает риск»: хвост Рэлея $e^{-h^2/2\sigma^2}$ тяжелее гауссовского хвоста для максимумов, потому что гауссов хвост описывает «случайную точку», а не «вершину волны»; $P(\text{гребень}\gt3\sigma)=e^{-4{,}5}=1{,}1\%$ против $0{,}13\%$ для случайной точки.

Вне слайдов

Рэлеевость огибающей узкополосного гауссовского процесса — результат Райса (1945); имя Слепяна связано с моделью Слепяна (1963) — описанием формы процесса в окрестности высокого пересечения уровня (выброс при большом $u$ ведёт себя как парабола со случайной кривизной); на слайде «теоремой Слепяна» названо следствие о рэлеевости пиков. Площадь $S$ для высокого $u$ и гладкого процесса $\approx\tfrac23HL$ (парабола). Расчёт огибающей: np.abs(scipy.signal.hilbert(x)).

5.5. Кластеризация экстремумов (сл. 21)

Наблюдение: в реальных данных превышения уровня $u$ часто идут «пачками». Два механизма: (1) нестационарность — дисперсия $\sigma(t)$ меняется во времени (сезонность, дрейф); (2) долгая память / нелинейность — высокое значение предсказывает следующее высокое. Следствие для формулы Райса: наивная формула не учитывает кластеризацию — она считает превышения независимыми; решение — декластеризация перед применением EVT. Extremal index $\theta\in(0,1]$: доля «независимых» экстремумов; $\theta=1$ — нет кластеризации (пуассоновский случай) (сл. 21).

На сгенерированном процессе видно, что превышения уровня идут пачками: несколько выбросов подряд, долгая пауза, новая пачка. Первый механизм — нестационарность: периоды малой и большой дисперсии; при большой дисперсии превышений много, при малой — мало; примеры: сезонные изменения нагрузки на энергосистему или сервер, суточный ритм биосигналов — частота сердцебиения во сне ниже и с меньшей дисперсией, чем при бодрствовании. Второй — долгая память или нелинейность: высокое значение сегодня предсказывает высокое завтра, характерно для финансовых рядов — после большого скачка вниз серия нестабильных значений. Проблема: формула Райса предполагает, что каждое пересечение независимо от предыдущего, а при кластеризации пересечения «притягиваются» — наивная формула переоценивает число независимых событий. Решения: декластеризация — выделить независимые кластеры и применять теорию экстремальных значений к каждому; мера кластеризации — индекс экстремальности $\theta$: при $\theta=1$ кластеризации нет, превышения пуассоновские; при $\theta\lt1$ эффективное число независимых экстремумов $\theta\cdot N^+$, где $N^+$ — из формулы Райса.

На пальцах

Кластеризация — «после грозы дождь идёт пачками»: если дисперсия ряда сама по себе гуляет (Лекция 2: режимы волатильности), выбросы приходят кучно, и считать их независимыми тревогами нельзя. $\theta$ — «сколько независимых событий на одно превышение»: $\theta=0{,}25$ означает, что четыре подряд превышения — это одно событие. В песочнике: узкополосный процесс с переключением дисперсии, уровень $2{,}5\sigma$: 772 превышения, 193 кластера (пауза $\gt20$ отсчётов — новый кластер), $\hat\theta\approx0{,}25$.

Вне слайдов

Декластеризация «по прогонам» (runs declustering): превышения, разделённые паузой не длиннее $r$ отсчётов, объединяются в кластер; $\hat\theta=$ число кластеров / число превышений. Более формальная оценка без выбора $r$ — интервальный оценщик Ферро–Сегерса (2003). Для узкополосного процесса кластеризация внутри одного выброса «встроена» (соседние отсчёты над уровнем зависимы) — формула Райса считает восходящие пересечения, а не отсчёты над уровнем, поэтому корректно сравнивать $\theta$ с числом пересечений, а не с числом точек. Раздел 3. Вопросы для подготовки к защите лабораторных (теория)

Формат ответа: сначала тезис (1–2 предложения), затем аргументация от лица студента; ссылки на слайды и таймкоды — для самопроверки.

1. Что такое восходящее пересечение и выброс, и как их корректно посчитать по дискретному ряду?

Тезис: восходящее пересечение — момент, когда $X=u$ при $\dot X\gt0$; выброс — интервал, где $X\gt u$, он начинается восходящим пересечением; по ряду пересечения считают по смене знака $X-u$, а устойчивая форма — np.sum((x[:-1] < u) & (x[1:] >= u)), которая не теряет точки ровно на уровне.

Аргументация (сл. 4–5; запись 06:32–13:25; ноутбук, разд. 2): $\operatorname{sign}$ даёт 0 на уровне, и np.diff(np.sign(x-u))==2 пропустит переход $-1\to0\to+1$. Частота $\hat\nu^+(u)=N^+/T$ максимальна при $u=0$ и падает с $u$; выброс задаёт длину $L$, высоту $H$, площадь $S$. Симметрия $\nu^+(u)=\nu^-(-u)$ — только при нулевом среднем и симметричном распределении.

2. Почему у двух процессов с одинаковой дисперсией число пересечений нуля может отличаться в разы?

Тезис: частота пересечений зависит не от размаха, а от скорости изменения — дисперсии производной $\lambda_2=D[\dot X]$: гладкий узкополосный процесс пересекает ноль редко, зашумлённый широкополосный — почти на каждом отсчёте.

Аргументация (сл. 6; запись 15:55–18:24): по формуле Райса $\nu^+(0)=\frac1{2\pi}\sqrt{\lambda_2/\lambda_0}$; при $\lambda_0=1$ узкополосный AR(2) имеет $\lambda_2=0{,}40$ и $\nu^+(0)=0{,}10$, широкополосный AR(1) — $\lambda_2=2{,}9$ и $\approx0{,}27$ (ноутбук). Дифференцирование умножает спектр на $\omega^2$, поэтому $\lambda_2$ — «масса спектра на высоких частотах».

3. Что такое спектральные моменты, как их оценить по данным и где типичная ошибка нормировки?

Тезис: $\lambda_n=\int_0^\infty\omega^nS(\omega)d\omega$: $\lambda_0$ — дисперсия, $\lambda_2$ — дисперсия производной, $\lambda_1$ — центр тяжести спектра; по ряду — взвешенные суммы периодограммы $\sum\omega_k^nP(f_k)\Delta f$; ошибка — умножить на $\Delta\omega=2\pi\Delta f$ вместо $\Delta f$ (получится $\lambda_0=2\pi\sigma^2$).

Аргументация (сл. 7–8, 10; запись 18:24–35:30; ноутбук, разд. 3): scipy.signal.periodogram нормирован так, что $\sum P\Delta f=\sigma^2$ — контроль $\hat\lambda_0\approx\operatorname{Var}(x)$; DC-бин отбрасывают, ряд центрируют; единицы Гц$^n\cdot$(ед.)$^2$, для угловых частот множитель $(2\pi)^n$. $\lambda_2$ конечна только при спектре, убывающем быстрее $\omega^{-3}$ (дифференцируемость).

4. Что измеряет параметр полосы $\varepsilon$, каковы его пределы и почему у белого шума он равен 0,5, а не 1?

Тезис: $\varepsilon=\sqrt{1-\lambda_1^2/(\lambda_0\lambda_2)}\in[0,1]$ — мера неравномерности спектра (0 — одна линия); для плоского спектра на $[0,f_s/2]$ дробь равна $3/4$ и $\varepsilon=0{,}5$ точно; значения около 1 требуют энергии одновременно у нуля и у частоты Найквиста.

Аргументация (сл. 9; запись 24:47–30:22; ноутбук, разд. 5): неравенство Коши–Буняковского даёт $\lambda_1^2\le\lambda_0\lambda_2$; правило слайда — $\lt0{,}3$ узкополосный, $\gt0{,}7$ широкополосный, $0{,}3$–$0{,}7$ инженерные сигналы; строка таблицы «$\approx1$ — белый шум» неточна (подпись $\varepsilon=0{,}5$ на рисунке верна). Красный спектр с пиком у нуля даёт $\varepsilon\gt0{,}5$ независимо от остроты пика (солнечные пятна $0{,}555$) — интерпретировать осторожно.

5. Выведите идею формулы Райса: откуда под интегралом скорость и почему нужны совместная нормальность и некоррелированность $X$ и $\dot X$?

Тезис: пересечение — событие $\{X=u,\dot X\gt0\}$, а число пересечений в единицу времени пропорционально скорости прохождения уровня, поэтому $\nu^+(u)=\int_0^\infty\dot x\,p(u,\dot x)d\dot x$; для стационарного гауссовского процесса $X$ и $\dot X$ совместно нормальны и некоррелированы (значит, независимы), интеграл берётся явно и даёт $\frac1{2\pi}\sqrt{\lambda_2/\lambda_0}\,e^{-u^2/2\lambda_0}$.

Аргументация (сл. 11–12; запись 38:30–49:05): некоррелированность — $\mathbb{E}[X\dot X]=\tfrac12\frac{d}{dt}\mathbb{E}X^2=0$ из стационарности; $X\sim\mathcal{N}(0,\lambda_0)$, $\dot X\sim\mathcal{N}(0,\lambda_2)$; $\int_0^\infty\dot x\varphi(\dot x)d\dot x=\sqrt{\lambda_2/2\pi}$; произведение — «темп нулевых пересечений» на «хвост нормального распределения». Райс, Bell Labs, 1944–45.

6. Когда формула Райса применима, а когда даёт лишь границу или ошибается? Как это проверить на данных?

Тезис: три условия — стационарность, гауссовость, дифференцируемость (и умеренный $u$, иначе мало событий); при тяжёлых хвостах формула занижает (нижняя граница), при скошенных данных — не годится без трансформации, а для «недифференцируемых» широкополосных последовательностей завышает.

Аргументация (сл. 14; запись 1:01:55–1:03:17; ноутбук, разд. 4, 7): верификация на AR(2) — расхождение $\sim1\%$; для AR(1) с $\varphi=0{,}1$ формула даёт $0{,}272$ против точных дискретных $\arccos(\rho_1)/2\pi=0{,}235$, для белого шума $0{,}289$ против $0{,}25$; солнечные пятна: асимметричная кривая $\hat\nu^+(u)$ (ноль слева от $-1{,}2\sigma$) — визуальный тест на негауссовость; лечение — $\sqrt x$ или $\log(x+1)$.

7. Насколько стабильно число пересечений между реализациями? Что означает «пуассоновское приближение»?

Тезис: точная дисперсия $\operatorname{Var}[N^+]$ (Райс, 1945) требует двумерной плотности и численного интегрирования; на практике при высоких уровнях $\operatorname{Var}\approx\mathbb{E}$ — редкие превышения образуют пуассоновский поток; при низких уровнях у узкополосного процесса пересечения регулярнее пуассоновских ($\operatorname{Var}/\mathbb{E}\ll1$).

Аргументация (сл. 13; запись 49:05–57:41): по 200 реализациям AR(2) индекс дисперсии $0{,}05$ при $u=0$, $0{,}34$ при $1\sigma$, $0{,}77$ при $2{,}5\sigma$ — растёт к 1 (песочница); синусоида пересекает ноль детерминированно, поэтому узкополосный процесс «почти по расписанию». Уточнение к слайду: к 1 стремится $\operatorname{Var}/\mathbb{E}$, а не $\sqrt{\operatorname{Var}}/\mathbb{E}$.

8. Как по $\varepsilon$ и частоте нулевых пересечений сузить класс модели и оценить её масштаб?

Тезис: четыре шага — $\hat\lambda_{0,1,2}$ по ДПФ, $\hat\varepsilon$, класс КФ по таблице (гауссова $0{,}05$–$0{,}2$, экспоненциальная $0{,}5$–$0{,}7$, степенная $0{,}7$–$0{,}95$), параметры по $\lambda_0$ и $\nu^+(0)$; для гауссовой КФ $e^{-\tau^2/2l^2}$ масштаб $l=1/(2\pi\nu^+(0))$.

Аргументация (сл. 15–16; запись 1:03:17–1:14:59): пример подшипника — $\hat\varepsilon=0{,}25$ ⇒ узкополосный, гауссова КФ, $\hat l$ из $\nu^+(0)$ и $\hat\lambda_0$; ограничения — только стационарные гауссовские процессы, при $\varepsilon\approx0{,}5$ классы трудно различить. Метод экономит перебор моделей Лекции 3, но не заменяет ACF/PACF и диагностику остатков.

9. Как связаны средняя длина выброса, частота пересечений и вероятность превышения уровня?

Тезис: точное тождество $\mathbb{E}[L]\cdot\nu^+(u)=P(X\gt u)$ — доля времени над уровнем равна числу выбросов в единицу времени, умноженному на среднюю длину; отсюда $\mathbb{E}[L]=P(X\gt u)/\nu^+(u)$, для гауссовского процесса $P(X\gt u)=\tfrac12\operatorname{erfc}(u/\sqrt{2\lambda_0})$.

Аргументация (сл. 17–18; запись 1:19:12–1:23:26; ноутбук, разд. 6): выше уровень — выбросы реже и короче, но выше; уже полоса — длиннее; проверка: $u=0{,}5\sigma$ — $3{,}46$ (тождество) против $3{,}50$ (эмпирика), $1\sigma$ — $2{,}59/2{,}66$, $2\sigma$ — $1{,}66/1{,}81$. Формула Картрайта в виде, напечатанном на сл. 18, даёт $\approx51$ и не согласуется — на защите опираться на тождество.

10. Как распределены высоты выбросов и пики узкополосного процесса, и почему «наивный» гауссовский расчёт занижает риск?

Тезис: у узкополосного гауссовского процесса огибающая $R=\sqrt{X^2+\hat X^2}$ и её пики распределены по Рэлею с масштабом $\sigma$ (не по Гауссу); хвост Рэлея для вершин волн тяжелее гауссовского хвоста для «случайной точки», поэтому вероятность высокого пика, посчитанная по $\mathcal{N}(0,\sigma^2)$, занижена.

Аргументация (сл. 19–20; запись 1:23:26–1:30:40): $P(R\gt3\sigma)=e^{-4{,}5}=1{,}1\%$ против $0{,}13\%$ для $X\gt3\sigma$; проверка в песочнике — масштаб Рэлея огибающей $1{,}00$ при $\sigma=1$, пиков $0{,}92$; высоты над уровнем $u$ — условное распределение $\max-u$. Параметр $b=\sigma\varepsilon/\sqrt2$ со сл. 19 симуляцией не подтверждается (даёт $0{,}17$ против $\approx0{,}74$ по MLE) — на защите называть масштаб $\sigma$ и условие $\varepsilon\lt0{,}3$.

11. Что такое кластеризация экстремумов, почему она ломает формулу Райса и что такое extremal index?

Тезис: при нестационарной дисперсии или долгой памяти превышения идут пачками, а формула Райса считает их независимыми и переоценивает число независимых событий; $\theta\in(0,1]$ — доля независимых экстремумов ($\theta=1$ — пуассоновский случай), эффективное число событий $\theta N^+$; перед EVT — декластеризация.

Аргументация (сл. 21; запись 1:30:40–1:36:29): механизмы — сезонность/дрейф $\sigma(t)$ (энергопотребление, пульс во сне и при бодрствовании), финансовые ряды после скачка; оценка $\hat\theta$ = кластеры/превышения при декластеризации «по прогонам» (песочница: 772 превышения, 193 кластера, $\hat\theta\approx0{,}25$); связь с режимами волатильности HMM (Лекция 2).

12. Что показал ноутбук лектора на реальных данных, и какие выводы из него важны для ЛР?

Тезис: на солнечных пятнах ($\varepsilon=0{,}555$, красный спектр) формула Райса не работает из-за скошенности — кривая $\hat\nu^+(u)$ асимметрична, нужна трансформация; на логдоходностях SPY ($\varepsilon=0{,}47$, плоский спектр) $\varepsilon$ почти не меняется между спокойным 2019 и кризисным 2020 годом, хотя $\sigma$ выросла втрое — $\varepsilon$ характеризует форму спектра, а не масштаб.

Аргументация (ноутбук, разд. 7; п. 6.2): $\varepsilon$ смещается вверх при пике у нуля частот (11-летний цикл), поэтому «периодичный» ряд может иметь $\varepsilon$ выше, чем шум; надёжная интерпретация — при пике вблизи середины диапазона; для доходностей интерес представляет не $\varepsilon$, а $\lambda_0$ и кластеризация. Пороги классов в ноутбуке и на слайде расставлены по-разному — на защите цитировать слайд.

4.1. Прямые указания лектора (слайды + запись + ноутбук)

  1. Четыре умения после лекции: оценивать спектральные моменты по периодограмме и взвешенной сумме; определять тип КФ по $\varepsilon$; предсказывать $\nu^+(u)$ по формуле Райса; оценивать длину и высоту выброса по приближениям Картрайта и Рэлея (сл. 22; запись 1:37:57–1:39:24).
  2. Считать пересечения по смене знака $X-u$; в ноутбуке — устойчивая форма np.sum((x[:-1] < u) & (x[1:] >= u)), а также счёт всех пересечений нуля и локальных экстремумов (сл. 5; запись 10:24–11:47; ноутбук, разд. 2).
  3. Спектральные моменты — три шага через scipy.signal.periodogram; следить за единицами (Гц$^n\cdot$ед.$^2$, множитель $(2\pi)^n$ для угловых частот) и за нормировкой: шаг $\Delta f$, не $\Delta\omega$; проверка $\hat\lambda_0\approx\sigma^2$ (сл. 10; запись 30:22–35:30; ноутбук, разд. 3).
  4. Сравнивать частоты пересечений только для уровней, нормированных по СКО (запись 59:17); верифицировать формулу Райса на модельных данных до применения к реальным (сл. 14; запись 57:41).
  5. Условия применимости формулы Райса — стационарный гауссовский дифференцируемый процесс, умеренный $u$; при тяжёлых хвостах — нижняя граница; при небольшом нарушении условий формула «не слишком неверна» (сл. 14; запись 1:01:55–1:03:17, 1:39:24–1:41:17).
  6. Идентификация по $\varepsilon$ — как первый шаг, сужающий класс модели до подбора параметров; при $\varepsilon\approx0{,}5$ классы трудноразличимы — нужен дополнительный анализ (сл. 15–16; запись 1:08:02–1:14:59).
  7. Для скошенных, неотрицательных рядов (солнечные пятна) — трансформация $\sqrt x$ или $\log(x+1)$ перед применением Райса; асимметрия $\hat\nu^+(u)$ — визуальный тест гауссовости (ноутбук, разд. 7).
  8. Для средней длины выброса пользоваться тождеством $\mathbb{E}[L]=P(X\gt u)/\nu^+(u)$ (в ноутбуке именно оно); высоты сопоставлять с Рэлеем через MLE (ноутбук, разд. 6).
  9. Проверять кластеризацию превышений: при нестационарной дисперсии или долгой памяти — декластеризация и extremal index $\theta$; наивная формула Райса переоценивает число независимых событий (сл. 21; запись 1:33:27–1:36:29).
  10. Следующая лекция — EVT (GEV, GPD, POT, декластеризация) и Deep Learning для временных рядов (сл. 22–23; запись 1:30:40, 1:41:17).

4.4. Чего в Лекции 6 нет / ловушки, которые стоит проверить

  • $\varepsilon$ белого шума — 0,5, а не 1 (сл. 9 против ноутбука и расчёта); красный спектр даёт $\varepsilon\gt0{,}5$, интерпретировать с оглядкой на положение пика.
  • Формула Райса для дискретных широкополосных рядов завышает частоту (недифференцируемость); контроль — $\arccos(\rho_1)/2\pi$.
  • Формула Картрайта (сл. 18) в напечатанном виде численно не согласуется; использовать тождество $\mathbb{E}[L]\nu^+=P(X\gt u)$.
  • Параметр Рэлея (сл. 19) $b=\sigma\varepsilon/\sqrt2$ не подтверждается; огибающая и пики узкополосного процесса — Рэлей с масштабом $\sigma$ (сл. 20, проверено).
  • Дисперсия числа пересечений (сл. 13): к 1 стремится индекс дисперсии $\operatorname{Var}/\mathbb{E}$; рисунок на слайде — старая версия (лектор показал правильный отдельно).
  • Рисунок сл. 11 нарисован с неверной осью (замечание лектора); смысл — верхняя половина линии $X=u$.
  • Дифференцируемость: $\lambda_2$ конечна только при спектре, убывающем быстрее $\omega^{-3}$; лоренцев спектр (экспоненциальная КФ) формально её не имеет — оценка $\hat\lambda_2$ зависит от $f_s$.
  • EVT, GEV/GPD/POT, оценка $\theta$ по Ферро–Сегерсу — следующая лекция; здесь только постановка.
  • Из программы курса: спектр и периодограмма — Лекция 5; ARMA-модели для классов КФ — Лекция 3; режимы волатильности как источник кластеризации — Лекция 2.

4.5. Скелет решения ЛР (исполнен в песочнице без ошибок)

import numpy as np
from scipy import signal
from scipy.stats import rayleigh, norm
from scipy.special import erfc
import statsmodels.api as sm
import warnings; warnings.filterwarnings("ignore")

# ---------- 0. Инструменты (сл. 5, 10, 12; ноутбук лектора) ----------
def spectral_moments(x, fs=1.0):
    """lambda_n = sum_k (2*pi*f_k)^n * P(f_k) * df; P — периодограмма (мощность/Гц), DC-бин отброшен."""
    f, p = signal.periodogram(x, fs=fs); f, p = f[1:], p[1:]
    w, df = 2 * np.pi * f, f[1] - f[0]
    l0, l1, l2 = (p * df).sum(), (w * p * df).sum(), (w ** 2 * p * df).sum()
    return l0, l1, l2, np.sqrt(max(0.0, 1 - l1 ** 2 / (l0 * l2)))

def upcrossings(x, u):                      # устойчивый счёт: не теряет точки, лежащие ровно на уровне
    return int(np.sum((x[:-1] < u) & (x[1:] >= u)))

def rice(u, l0, l2):                        # формула Райса, сл. 12
    return np.sqrt(l2 / l0) / (2 * np.pi) * np.exp(-u ** 2 / (2 * l0))

def excursions(x, u):                       # список выбросов: (start, end, высота H, длина L), сл. 17
    above = (x > u).astype(int); d = np.diff(np.concatenate([[0], above, [0]]))
    s, e = np.where(d == 1)[0], np.where(d == -1)[0]
    return [(a, b, x[a:b].max() - u, b - a) for a, b in zip(s, e)]

def ar2(n, r=0.97, w0=np.pi / 5, seed=0):   # узкополосный: комплексные полюса радиуса r
    rng = np.random.default_rng(seed); x = np.zeros(n); e = rng.standard_normal(n); a1, a2 = 2 * r * np.cos(w0), -r ** 2
    for t in range(2, n): x[t] = a1 * x[t - 1] + a2 * x[t - 2] + e[t]
    return (x - x.mean()) / x.std()

# ---------- 1. Спектральные моменты, eps, формула Райса против эмпирики (сл. 7-12, 14) ----------
T = 50_000
x_narrow = ar2(T)
rng = np.random.default_rng(1); x_wide = (lambda e: (e - e.mean()) / e.std())(signal.lfilter([1], [1, -0.1], rng.standard_normal(T)))
for name, x in (("узкополосный AR(2)", x_narrow), ("широкополосный AR(1), phi=0.1", x_wide)):
    l0, l1, l2, eps = spectral_moments(x); rho1 = np.corrcoef(x[:-1], x[1:])[0, 1]
    print(f"{name}: lambda0={l0:.3f} lambda2={l2:.3f} eps={eps:.3f} | nu+(0): Райс={rice(0, l0, l2):.4f}, "
          f"эмпирика={upcrossings(x, 0) / T:.4f}, точная дискретная arccos(rho1)/2pi={np.arccos(rho1) / (2 * np.pi):.4f}")
l0, l1, l2, eps = spectral_moments(x_narrow)
for u in (0.0, 1.0, 2.0, 3.0):
    print(f"  u={u:.0f}sigma: Райс {rice(u, l0, l2):.4f} vs эмпирика {upcrossings(x_narrow, u) / T:.4f}")

# ---------- 2. Разброс числа пересечений: индекс дисперсии Var/E -> 1 при высоких u (сл. 13) ----------
cnt = {u: [] for u in (0.0, 1.0, 2.5)}
for i in range(200):
    xi = ar2(5000, seed=100 + i)
    for u in cnt: cnt[u].append(upcrossings(xi, u))
print("индекс дисперсии Var/E:", {u: round(np.var(c) / np.mean(c), 2) for u, c in cnt.items()}, "(1 = пуассоновский поток)")

# ---------- 3. Идентификация класса КФ по eps (сл. 15-16) ----------
def kf_class(e): return "гауссова (узкополосный)" if e < 0.3 else ("переходный класс" if e < 0.7 else "степенная / широкополосный")
print("класс КФ:", kf_class(eps), f"(eps={eps:.2f}); масштаб из nu+(0): 1/nu+(0) = {1 / rice(0, l0, l2):.1f} отсчётов на период")

# ---------- 4. Выбросы: длина L (тождество E[L]*nu+ = P(X>u)), высота H и огибающая (сл. 17-20) ----------
for u in (0.5, 1.0, 2.0):
    ex = excursions(x_narrow, u); p_above = 0.5 * erfc(u / np.sqrt(2 * l0))
    print(f"u={u}: выбросов {len(ex)}, E[L] эмп.={np.mean([e[3] for e in ex]):.2f}, тождество P(X>u)/nu+={p_above / rice(u, l0, l2):.2f}, "
          f"E[H] эмп.={np.mean([e[2] for e in ex]):.2f}")
env = np.abs(signal.hilbert(x_narrow))       # огибающая узкополосного процесса (теорема Слепяна)
print(f"огибающая R(t): Рэлей, MLE-масштаб={rayleigh.fit(env, floc=0)[1]:.3f} (теория: sigma=1); "
      f"пики x: масштаб={rayleigh.fit(x_narrow[signal.argrelmax(x_narrow)[0]].clip(min=1e-9), floc=0)[1]:.3f}")

# ---------- 5. Кластеризация: индекс экстремальности через декластеризацию (сл. 21) ----------
vol = np.where((np.arange(T) // 2000) % 2 == 0, 0.6, 1.6)   # нестационарная дисперсия => "пачки" превышений
x_cl = x_narrow * vol; u = 2.5 * x_cl.std()      # узкополосный процесс с переключением дисперсии
exc = np.where(x_cl > u)[0]; gaps = np.diff(exc); run = 20      # runs-декластеризация: новый кластер, если пауза > run отсчётов
n_clusters = 1 + np.sum(gaps > run); theta = n_clusters / len(exc)
print(f"превышений {len(exc)}, кластеров {n_clusters}, extremal index theta≈{theta:.2f} (1 = нет кластеризации)")

# ---------- 6. Реальные данные: солнечные пятна (statsmodels), негауссовость (ноутбук, разд. 7) ----------
s = sm.datasets.sunspots.load_pandas().data["SUNACTIVITY"].values.astype(float); s -= s.mean()
l0s, l1s, l2s, eps_s = spectral_moments(s)
print(f"солнечные пятна: N={len(s)}, eps={eps_s:.3f}, nu+(0): Райс={rice(0, l0s, l2s):.4f}, эмпирика={upcrossings(s, 0) / len(s):.4f}; "
      f"nu+(-1.5sigma) эмп.={upcrossings(s, -1.5 * s.std()) / len(s):.4f} vs nu+(+1.5sigma)={upcrossings(s, 1.5 * s.std()) / len(s):.4f} (асимметрия => не гауссов)")
