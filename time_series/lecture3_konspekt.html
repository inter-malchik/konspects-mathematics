§1. AR(p): авторегрессионные процессы (сл. 3–6)

1.1. Определение AR(p) и мотивация (сл. 3)

Модель AR($p$): $$\underbrace{X_t}_{\text{текущее}}=\underbrace{\varphi_1X_{t-1}+\dots+\varphi_pX_{t-p}}_{\text{взвешенная сумма }p\text{ прошлых}}+\underbrace{\varepsilon_t}_{\text{белый шум}}.$$ Оператор лага $B^kX_t=X_{t-k}$: $$\varphi(B)\,X_t=\varepsilon_t,\qquad \varphi(z)=1-\varphi_1z-\dots-\varphi_pz^p.$$ Интуиция: текущее значение — взвешенная сумма прошлых плюс белый шум. Пример: потребление электроэнергии в час $t$ определяется предыдущими часами (суточный паттерн нагрузки). Сноска слайда: белый шум (англ. white noise) в литературе по VAR и импульсным откликам называют также innovation, disturbance, shock (сл. 3).

Из записи лекции [02:52–07:58]

Самый простой вопрос: как предсказать следующее значение ряда? Естественный ответ — посмотреть на предыдущее. Авторегрессия — «регрессия на самого себя»: модель смотрит на собственные прошлые значения; моменты, из которых они взяты, называются лагами (временные сдвиги в прошлое). Уравнение AR($p$): текущее значение — взвешенная сумма $p$ предыдущих плюс белый шум; коэффициенты $\varphi_1,\dots,\varphi_p$ — веса, оцениваемые из данных, как параметры при признаках в регрессии; только «признаки» здесь — значения одного и того же признака в разные моменты времени. Оператор лага $B$ — удобное сокращение: $BX_t=X_{t-1}$, $B^kX_t=X_{t-k}$; всё уравнение сворачивается в короткую запись $\varphi(B)X_t=\varepsilon_t$.

Пример: потребление электроэнергии в час $t$ сильно зависит от потребления час назад — и два, и три часа назад, потому что есть суточный паттерн (картинка была на первой лекции). Терминология: белый шум в литературе называют инновацией, возмущением, а в классических текстах по Боксу–Дженкинсу — «шоком»: к чётко описанной зависимости добавляется шоковая составляющая, которая «встряхивает» модель; в русских переводах «шок» тоже встречается.

На пальцах

AR($p$) — «прогноз по инерции с $p$ шагами памяти»: завтрашняя температура ≈ $0{,}7\cdot$сегодняшняя $+0{,}2\cdot$вчерашняя $+$ случайная поправка. Оператор лага — это «кнопка назад»: $B$ сдвигает ряд на один шаг, $B^2$ — на два. Многочлен $\varphi(z)$ — «паспорт» модели: в нём записаны все веса, и, как увидим на следующем слайде, его корни говорят, стационарна ли модель.

1.2. Условие стационарности AR(p) (сл. 4)

Условие стационарности: все корни $\varphi(z)=0$ лежат вне единичного круга: $|z_i|\gt1\ \ \forall i$. AR(1): $\varphi(z)=1-\varphi_1z$, корень $z=1/\varphi_1$; условие $|\varphi_1|\lt1$. Граница: $\varphi_1=1$ ⇒ случайное блуждание — нестационарен (см. лекцию 1). Физический смысл: процесс «не убегает на бесконечность» (сл. 4).

Рисунок (сл. 4). Комплексная плоскость Re/Im, единичная окружность $|z|=1$ с отметками $-1$ и $1$. Красная точка внутри круга — «нестац., $|z|\lt1$»; зелёная точка снаружи — «стац., $|z|\gt1$».

При каких условиях AR($p$) описывает стационарный процесс? Записываем характеристический полином $\varphi(z)$ (где $z$ соответствует оператору задержки), приравниваем нулю, ищем корни. Условие: все корни лежат вне единичного круга, $|z_i|\gt1$. Зелёная точка — корень снаружи, процесс стационарен; красная — внутри, нестационарен; корень ровно на окружности — тоже нестационарен. Физический смысл: если корень внутри, возмущения не просто не затухают, а нарастают, и процесс «убегает на бесконечность». Для AR(1) полином даёт $z=1/\varphi_1$, откуда $|\varphi_1|\lt1$. Расхождение (10:32). В записи прозвучало «$1/\varphi_1$ должно быть больше нуля по модулю» — оговорка: по слайду и по смыслу — больше единицы по модулю; лектор тут же переходит к верному выводу $|\varphi_1|\lt1$. Граничный случай $\varphi_1=1$ — случайное блуждание с первой лекции; корень ровно на границе круга.

На пальцах

Каждый корень $z_i$ — это «скорость затухания» одной из составляющих памяти: вклад прошлого убывает как $(1/z_i)^k$. Корень снаружи круга ($|z_i|\gt1$) — вклад затухает; на окружности — не затухает (блуждание); внутри — растёт (взрыв). Для AR(1) это ровно три режима $|\varphi|\lt1$, $=1$, $\gt1$ со сл. 16 Лекции 1, только записанные через корень $1/\varphi$. Проверка на практике: ArmaProcess(ar=[1, -phi1, -phi2]).isstationary; для AR(2) с $\varphi_1=0{,}6$, $\varphi_2=0{,}3$ (сл. 5) модули корней $3{,}08$ и $1{,}08$ — стационарна, но второй корень близко к границе, поэтому память длинная.

Вне слайдов

Условие на корни характеристического полинома $\varphi(z)$ эквивалентно тому, что корни «обратного» полинома $z^p-\varphi_1z^{p-1}-\dots-\varphi_p$ лежат внутри круга — в литературе встречаются обе формулировки, и ArmaProcess.arroots возвращает корни именно $\varphi(z)$ (должны быть $\gt1$ по модулю). Комплексные корни дают затухающие колебания в ACF (осцилляции, о которых говорилось на Лекции 1).

1.3. ACF и PACF для AR(p) (сл. 5)

Уравнения Юла–Уокера (результат): $$\rho_k=\varphi_1\rho_{k-1}+\dots+\varphi_p\rho_{k-p}.$$ Ключевое правило: PACF AR($p$) обрывается после лага $p$ — главный диагностический признак. Определения ACF и PACF — см. лекцию 1; здесь — что из них следует для AR (сл. 5).

AR(1), $\varphi_1=0{,}8$: ACF плавно убывает от 1 ($0{,}8;\ 0{,}64;\ 0{,}5\dots$), PACF — один столбик $\approx0{,}8$ на лаге 1 и подпись «обрыв после лага 1». Уравнения Юла–Уокера связывают коэффициенты $\varphi$ с автокорреляциями $\rho_k$ — принимаем без вывода. Главное правило, которое из них следует: PACF для AR($p$) обрывается сразу после лага $p$ — все последующие значения статистически незначимы, лежат внутри пунктирных полос (как задаются полосы, обсуждали на первой лекции). Разбор рисунка: при $\varphi_1=0{,}8$ ACF плавно затухает, PACF даёт один значимый лаг (нулевой лаг за лаг не считаем — там всегда единица), дальше обрыв — «идеальная картина» AR(1). Для AR(2) ACF плавно убывает, PACF обнуляется после второго лага. Плавное убывание ACF плюс резкий обрыв PACF после лага $p$ — признак AR($p$); прикладная задача сводится к тому, чтобы построить графики и найти, где обрыв на PACF, если он там есть.

На пальцах

Юл–Уокер «на пальцах»: у AR(1) $\rho_k=\varphi^k$ — та же геометрическая лесенка, что на Лекции 1; у AR(2) первые два значения задают рекуррентную формулу, и дальше ACF «катится» по ней: $\rho_1=\varphi_1/(1-\varphi_2)=0{,}857$, $\rho_2=\varphi_1\rho_1+\varphi_2=0{,}814$ (проверено). PACF на лаге 2 у AR(2) равна ровно $\varphi_2=0{,}3$ — поэтому столбик на рисунке такой высоты. Практическое чтение: считаем значимые столбики PACF до первого «провала в полосу» — это кандидат в $p$.

1.4. Оценка параметров AR(p) (сл. 6)

МНК = ММП при гауссовских ошибках: функция правдоподобия совпадает с суммой квадратов остатков ⇒ оба метода дают одинаковое $\hat\varphi$. Матричная форма МНК: $$\hat\varphi=(X^{\top}X)^{-1}X^{\top}y,\qquad X=\begin{pmatrix}X_p & X_{p-1} & \cdots & X_1\\ X_{p+1} & X_p & \cdots & X_2\\ \vdots & & & \vdots\\ X_{T-1} & X_{T-2} & \cdots & X_{T-p}\end{pmatrix}.$$ Строки $X$ — векторы лагов $[X_{t-1},\dots,X_{t-p}]$. Вывод: стандартные ошибки $\hat\varphi_k$ и $t$-тесты на значимость получаются из ковариационной матрицы $\widehat{\operatorname{Var}}(\hat\varphi)=\hat\sigma^2(X^{\top}X)^{-1}$ (сл. 6).

Хорошая новость: для авторегрессии почти ничего не меняется по сравнению с обычной регрессией из прошлого семестра — поиск коэффициентов сводится к обычной регрессии, которую решаем методом наименьших квадратов. Строим матрицу $X$ — раньше она называлась матрицей «объекты–признаки», теперь признаки — значения одного и того же признака с разными лагами; каждая строка — вектор лагов; вектор $y$ — сам ряд, сдвинутый на соответствующие позиции; дальше стандартная формула МНК. Свойство: МНК и метод максимального правдоподобия дают одинаковый результат — но только при гауссовских ошибках, когда правдоподобие сводится к сумме квадратов остатков; использовать можно любой из двух. Из оценок сразу получаем стандартные ошибки коэффициентов и проверяем каждый $\varphi$ на значимость $t$-тестом — как в прошлом семестре.

§2. MA(q): процессы скользящего среднего (сл. 7–9)

2.1. Определение MA(q) (сл. 7)

Модель MA($q$): $$X_t=\underbrace{\varepsilon_t+\theta_1\varepsilon_{t-1}+\dots+\theta_q\varepsilon_{t-q}}_{\text{скользящее среднее по белому шуму}},\qquad X_t=\theta(B)\,\varepsilon_t.$$ Ключевое отличие от AR: белый шум $\varepsilon_{t-j}$ при $j\gt q$ полностью забыт — конечная память. Пример: кратковременный скачок нагрузки на сервер затухает ровно через $q$ периодов (сл. 7).

Рисунок (сл. 7). Ось времени с отметками $t-3,\dots,t+2$; стрелки $\varepsilon$ на каждой отметке; закрашенный прямоугольник «окно памяти $q=3$» накрывает $t-3\dots t$; стрелки правее пунктирной границы помечены «не влияет на $X_t$».
Из записи лекции [21:27–26:07]

Порядок MA обозначают $q$, чтобы не путать с $p$ у авторегрессии. Интуиция: на систему периодически воздействуют случайные возмущения — белый шум; каждое возмущение влияет на поведение системы ровно $q$ периодов, а потом полностью исчезает; к тому времени, скорее всего, поступит новое возмущение, и не одно. На диаграмме стрелки — шумы $\varepsilon$, закрашенный прямоугольник — окно памяти шириной $q=3$; всё левее его левой границы на $X_t$ уже не влияет. В формуле $X_t$ — взвешенная сумма текущего и $q$ прошлых шумов. Ключевое словосочетание — «конечная память»: у AR($p$) память бесконечная, затухает экспоненциально, но никогда не обнуляется; у MA($q$) память ровно на $q$ шагов — и всё.

На пальцах

MA($q$) — «эхо толчков»: каждый новый толчок $\varepsilon_t$ слышен ещё $q$ шагов с весами $\theta_1,\dots,\theta_q$, а затем обрывается. Отсюда ACF, равная нулю после лага $q$: значения, разделённые более чем $q$ шагами, не имеют общих толчков. Сравните с AR: там толчок «переносится» через значения бесконечно, только всё тише.

У MA($q$) есть аналог условия стационарности — условие обратимости: записываем полином от коэффициентов $\theta$, приравниваем нулю, корни должны лежать вне единичного круга. Симметрия с AR: у авторегрессии обрывается PACF после лага $p$, а ACF затухает; у скользящего среднего наоборот — ACF обрывается после лага $q$, PACF затухает. На рисунке MA(1): ACF резко обрывается после первого лага, PACF колеблется и затухает; MA(2): ACF обрывается после второго лага. Столбик на третьем лаге MA(2) чуть выходит за пунктир — «достаточно близко, можно списать на погрешность»; PACF же после первого лага не обрывается, а по модулю даже растёт, прежде чем затухать, — это не погрешность и не обрыв.

Обратимость — «можно ли из ряда восстановить толчки»: $\varepsilon_t=X_t-\theta_1\varepsilon_{t-1}-\dots$ разворачивается в бесконечный ряд по прошлым $X$, и он сходится только при корнях вне круга. Для AR регрессоры $X_{t-1},X_{t-2},\dots$ наблюдаются напрямую, и МНК даёт готовую замкнутую формулу. Для MA регрессоры — прошлые белые шумы, которые мы не измеряем и не видим: они латентны. Поэтому «просто записать числа в матрицу и перемножить» не получится; приходится использовать ММП с итерационной оптимизацией: на каждой итерации рекурсивно восстанавливаем оценку $\hat\varepsilon_{t-j}$ и подставляем её в следующую итерацию. Название алгоритма не важно; важно, что это численная оптимизация, а не аналитическое решение. Следствие: при больших $q$ оценка MA заметно медленнее и вычислительно сложнее, чем AR, — ещё один фактор при выборе модели.

Студент: «так себе предположение». Лектор: «на пальцах» это сложнее, обещает расписать математику отдельным слайдом (как ранее для механизма внимания).

§3. ARMA(p, q): смешанные модели (сл. 10–11)

3.1. Определение и свойства ARMA(p, q) (сл. 10)

Уравнение ARMA($p,q$): $$\varphi(B)\,X_t=\theta(B)\,\varepsilon_t.$$ Условия стационарности и обратимости наследуются от AR- и MA-частей соответственно. Принцип экономии параметров: ARMA(1,1) часто заменяет AR($p$) при больших $p$: ARMA(1,1) — 2 параметра vs AR(6) — 6 параметров при сопоставимом качестве подгонки. Интуиция: один полюс ($\varphi$) задаёт затухание, один ноль ($\theta$) управляет формой начального отклика; вместе они гибко описывают широкий класс корреляционных структур (сл. 10).

Объединяем AR и MA в одну модель — ARMA, по-русски АРСС (авторегрессия — скользящее среднее); через оператор лага формула «простенькая». Условия стационарности и обратимости наследуются от частей — ничего нового. Зачем ARMA, если есть AR? Экономия параметров. Обозначения: ARMA(1,0) — это AR(1), ARMA(0,1) — MA(1). ARMA(1,1) — всего два параметра, $\varphi_1$ и $\theta_1$; AR(6) — шесть, а на практике ARMA(1,1) часто описывает данные не хуже AR шестого порядка: порядок авторегрессии снизили на пять, добавили один член скользящего среднего — и результат уже очень хороший. В ARMA(1,1) один параметр отвечает за скорость затухания, второй — за форму начального отклика; вдвоём они дают гибкую структуру при минимуме коэффициентов.

На пальцах

ARMA(1,1) — «эхо с затуханием»: толчок сразу отзывается с весом, заданным $\theta$, а потом гаснет геометрически со скоростью $\varphi$. Чтобы получить такую же форму отклика одной авторегрессией, нужно много членов — отсюда AR(6). Проверка на синтетическом ARMA(1,1) ($\varphi=0{,}7$, $\theta=0{,}5$, $T=600$): AIC/BIC у ARMA(1,1) — $1697/1711$, у AR(6) — $1706/1737$: две модели «одинаково хорошо подгоняют», но критерии предпочитают экономную.

Вне слайдов

Термины «полюс» и «ноль» — из теории передаточных функций: ARMA как линейный фильтр $X_t=\frac{\theta(B)}{\varphi(B)}\varepsilon_t$; нули полинома $\varphi$ — полюса передаточной функции (задают затухание/резонанс), нули $\theta$ — её нули (формируют начальный отклик). Любую стационарную обратимую ARMA можно записать как AR($\infty$) или MA($\infty$) — поэтому AR высокого порядка и есть «длинная» аппроксимация короткой ARMA.

«Идентифицировать модель» — определить её гиперпараметры: $p$ для AR, $q$ для MA, $p$ и $q$ для ARMA; только после этого подбираются параметры $\varphi,\theta$. Подход тот же — ACF и PACF, но новая сложность: у ARMA обе функции затухают и ни одна не обрывается, а на реальных данных графики зашумлены, и граница между «обрывается» и «медленно затухает» неочевидна. Что делать: по ACF/PACF выдвигаем гипотезу о структуре — AR, MA или, если обрывов нет, ARMA; для ARMA $p$ и $q$ подбираются по AIC или BIC (о них через несколько слайдов). Общее обязательное предположение всех трёх моделей — стационарность ряда; если она не выполняется, модели неприменимы; на практике ряды очень часто, «даже в большинстве случаев», нестационарны — чаще всего из-за тренда.

На пальцах

Идентификация — «диагноз по симптомам, подтверждённый анализом»: коррелограмма подсказывает класс и порядок, критерии AIC/BIC (пробуем сетку $p,q\le3$) выносят вердикт. Не стоит ждать чистого обрыва на реальных данных: столбики у самой полосы, «хвосты» из-за выбросов и сезонности — норма. Гипотеза + подтверждение + диагностика остатков (§5) — три уровня защиты от неверного порядка.

§4. ARIMA(p, d, q): нестационарные ряды (сл. 12–15)

4.1. Интегрирование и нестационарность (сл. 12)

Оператор разности: $$\Delta X_t=(1-B)X_t=X_t-X_{t-1}.$$ Порядок интегрирования $I(d)$: ряд стационарен после $d$ применений $\Delta$. ARIMA($p,d,q$): $$\varphi(B)\,(1-B)^d\,X_t=\theta(B)\,\varepsilon_t.$$ Случайное блуждание — $I(1)$: первая разность $\Delta X_t$ — белый шум (сл. 12).

Оператор разности $\Delta X_t$ — разность текущего и предыдущего значений, через оператор лага $(1-B)X_t$; он убирает линейный тренд, а применённый дважды — квадратичный. Если ряд становится стационарным после $d$ применений оператора разности, говорят, что ряд интегрирован порядка $d$ — $I(d)$, «I» от integrated. На рисунке: слева случайное блуждание с трендом; в середине первая разность — берём соседние значения, вычитаем, и так по всему ряду; здесь уже нет тренда, колебания около нуля — похоже на стационарный ряд; справа ACF первой разности быстро затухает — «всё в порядке». Модель ARIMA, по-русски АРПСС (авторегрессия — проинтегрированное скользящее среднее): три гиперпараметра $p$, $d$, $q$; $d$ — число применений оператора разности, порядок интегрирования. Уточнение лектора на вопрос: ряд именно дифференцируем — оператор разности есть дискретный аналог дифференцирования, конечные разности заменяют производные во многих численных алгоритмах.

На пальцах

Дифференцирование — «перейти от уровня к приростам»: вместо цены смотрим на доходность, вместо показаний одометра — на скорость. У блуждания приросты — чистый шум, у ряда с линейным трендом приросты колеблются вокруг константы (наклона), и стационарная ARMA описывает уже их. Буква «I» в ARIMA напоминает, что прогноз потом «интегрируется» обратно: приросты накапливаются в уровень. $I(0)$ — уже стационарен; $I(1)$ — одна разность; $I(2)$ — две (редко, см. 4.3).

Вне слайдов

$\Delta$ убирает линейный детерминированный тренд (остаётся константа — «дрейф»), а у стохастического тренда (блуждание) снимает единичный корень; в statsmodels ARIMA при $d\ge1$ дрейф задаётся trend='t'. Порядок операций: сначала $d$, потом $p,q$ — ACF/PACF читаются по продифференцированному ряду. Обратная операция (интегрирование) — кумулятивная сумма, поэтому прогноз уровня получают из прогноза приростов накоплением.

5.2. Диагностика остатков (сл. 17)

Что проверяем: остатки должны быть белым шумом — некоррелированы и нормально распределены. Тест Льюнга–Бокса: $$Q=n(n+2)\sum_{k=1}^{m}\frac{\hat\rho_k^2}{n-k}\ \sim\ \chi^2(m),$$ $H_0$: остатки некоррелированы; $p$-value $\lt0{,}05$ ⇒ модель недоспецифицирована. Q-Q plot: визуальная проверка нормальности (сл. 17).

Рисунок (сл. 17). «Диагностика остатков: норма (верхний ряд) vs проблема (нижний ряд)», по четыре панели. Норма: остатки — «трава» $\pm2$ вокруг нуля; ACF остатков внутри полосы; Q-Q — точки на диагонали; гистограмма симметричная, близкая к $\mathcal{N}(0,\sigma^2)$. Проблема: в остатках выброс до $-30$; в ACF несколько столбиков за полосой; Q-Q с загнутыми хвостами; гистограмма узкая, высокая, с длинным левым хвостом.
Из записи лекции [1:01:57–1:07:35]

Хорошая модель должна полностью объяснить структуру данных; всё, что осталось в остатках, должно быть белым шумом — некоррелированным и нормально распределённым (проверять нормальность умеем с прошлого семестра, «не бином Ньютона»). Остаток — значение модели минус реальное; остатков столько же, сколько элементов ряда, — это тоже временной ряд. Тест Льюнга–Бокса проверяет некоррелированность: $H_0$ — остатки некоррелированы; статистика $Q$ суммирует квадраты выборочных автокорреляций остатков. Расхождение (1:03:18). В записи прозвучало «если $p$-значение меньше 0,5»; лектор сразу уточняет: при уровне значимости $0{,}05$ — как на слайде; $p\lt0{,}05$ означает, что модель недоспецифицирована, в остатках осталась структура. Разбор рисунка: верхний ряд — хорошая модель: остатки похожи на белый шум со средним около нуля, все лаги ACF в полосе, точки Q-Q на диагонали, гистограмма симметричная; нижний ряд — проблемная: выброс в остатках, ACF кое-где выбивается, хвосты Q-Q загибаются, распределение «слишком высокое и без хвостов» — модель недоспецифицирована, вернуться к выбору $(p,q)$.

На пальцах

Льюнг–Бокс — «одним числом: есть ли ещё корреляция в остатках на первых $m$ лагах». Каждая $\hat\rho_k$ у белого шума мала (порядка $1/\sqrt n$), поэтому сумма квадратов, взвешенная $n(n+2)/(n-k)$, ведёт себя как $\chi^2$ с $m$ степенями свободы; большая $Q$ (маленькое $p$) — значит, где-то столбики выше, чем позволено случайностью. Q-Q plot — «сравнить квантили остатков с нормальными»: прямая линия — нормально; загнутые концы — тяжёлые хвосты или выбросы. Четыре панели сл. 17 стоит воспроизвести в ЛР один в один.

Вне слайдов

Для остатков оценённой ARMA($p,q$) число степеней свободы $\chi^2$ принимают $m-p-q$ (в statsmodels: acorr_ljungbox(resid, lags=[m], model_df=p+q, return_df=True)) — на слайде $\chi^2(m)$ соответствует тесту сырого ряда. $m$ обычно $10$–$20$ или $\min(10, n/5)$. Нормальность — тест Харке–Бера/Шапиро–Уилка плюс Q-Q; ненормальность при некоррелированности не рушит точечный прогноз, но искажает доверительные интервалы. Проверка полноты диагностики в песочнице: для ARMA(1,1) на своих данных $p$-value Льюнга–Бокса $0{,}65$ (10 лагов) и $0{,}73$ (20 лагов).

5.3. AIC и BIC: выбор порядка модели (сл. 18)

Формулы: $$\mathrm{AIC}=\underbrace{-2\ell}_{\text{качество подгонки}}+\underbrace{2k}_{\text{штраф за сложность}},\qquad \mathrm{BIC}=\underbrace{-2\ell}_{\text{качество подгонки}}+\underbrace{k\ln n}_{\text{штраф за сложность}},$$ $\ell$ — лог-правдоподобие, $k$ — число параметров, $n$ — объём выборки. Сравнение: BIC строже при $n\gt7$, поскольку $\ln n\gt2$; при больших $n$ BIC предпочтительнее. Оба указывают на одну модель ⇒ доверяем выбору. Критерии расходятся ⇒ обосновываем выбор содержательно (сл. 18).

Из записи лекции [1:07:35–1:10:13]

Информационные критерии сравнивают модели разных порядков (формулы упоминались на первой лекции). У AIC и BIC по два слагаемых: первое одинаковое, $-2\ell$, — качество подгонки: чем больше лог-правдоподобие, тем меньше слагаемое; второе — штраф за сложность: чем больше параметров, тем выше; $k$ — число параметров, а сила штрафа разная — $2k$ или $k\ln n$. Хорошая модель — с меньшим значением критерия. BIC штрафует сильнее: уже при $n=7$ натуральный логарифм больше 2, поэтому при выборках больше семи значений штраф BIC больше, и при больших выборках BIC предпочитает более простые модели. Правило: оба критерия указывают на одну модель — доверяем; расходятся — обосновываем выбор содержательно, исходя из задачи.

На пальцах

Оба критерия — «качество подгонки минус налог на параметры»: AIC берёт по 2 за параметр, BIC — по $\ln n$ (при $n=1000$ — почти 7). Поэтому на длинных рядах BIC «жаднее» и выбирает короткие модели, AIC чаще добавляет лишний член. В песочнице на ARIMA(1,1,1): AIC предпочёл $(3,0)$, BIC — $(1,1)$ — как раз тот случай, когда критерии разошлись и выбор пришлось обосновывать (истинный процесс — $(1,1)$, и он экономнее).

Вне слайдов

$\ln n\gt2$ ⇔ $n\gt e^2\approx7{,}39$, то есть для целых $n\ge8$ (при $n=7$: $\ln7=1{,}95\lt2$) — формулировка «$n\gt7$» на слайде верна для целых $n$. В statsmodels критерии доступны как res.aic, res.bic, есть и res.aicc — поправка AIC для малых выборок. Сравнивать критерии можно только у моделей, оценённых на одном и том же ряде с одним $d$ (после дифференцирования меняется выборка).

§6. Прогнозирование и кросс-валидация (сл. 19–21)

6.1. Прогнозирование ARIMA на h шагов (сл. 19)

Точечный прогноз: $$\hat X_{T+h\mid T}=\mathbb{E}[X_{T+h}\mid X_T,X_{T-1},\dots].$$ Дисперсия прогноза растёт с $h$ — неопределённость нарастает. Особенность ARIMA: $I(1)$ — прогноз сходится к константе; $I(2)$ — к линейному тренду. На графике: конус 95 % ДИ расширяется с горизонтом — это нормально (сл. 19).

Рисунок (сл. 19). «Прогноз ARIMA(1,1,1): расширяющийся конус неопределённости». Синяя траектория наблюдений 0–120, вертикальный пунктир «Момент $T=120$», оранжевая горизонтальная линия прогноза до 145 и светло-оранжевый веер 95 % ДИ, расширяющийся от $\pm$малого до $\pm35$.
Из записи лекции [1:10:13–1:13:13]

Когда модель оценена, ею можно прогнозировать. Точечный прогноз на $h$ шагов — условное математическое ожидание: $T$ — момент, до которого есть данные, $h$ — горизонт; берём всё, что знаем к моменту $T$, и считаем лучший прогноз в смысле минимальной среднеквадратичной ошибки. На практике важнее точечного прогноза доверительный интервал: чем дальше в будущее, тем шире конус. Это не артефакт, а честная картина нарастающей неопределённости: что будет сразу после конца выборки, предсказать можно более-менее точно, а через неделю, месяц, год — «полная неопределённость»; каждый шаг вперёд добавляет неопределённость и расширяет интервал.

На пальцах

Прогноз AR-части «забывает» последние наблюдения со скоростью $\varphi^h$ и стремится к среднему; у $I(1)$-ряда среднее приростов — константа, поэтому уровень стремится к горизонтали (как на рисунке), у $I(2)$ — к прямой с наклоном. Ширина конуса — накопленная дисперсия будущих толчков: для блуждания она растёт как $\sigma\sqrt h$. В песочнике для ARIMA(1,1,1) полуширина 95 % ДИ: $1{,}9$ при $h=1$, $12{,}7$ при $h=6$, $21{,}1$ при $h=12$, $32{,}1$ при $h=24$.

Вне слайдов

Сходимость к константе для $I(1)$ верна без дрейфа; с дрейфом (trend='t') прогноз $I(1)$ — прямая, $I(2)$ — парабола. res.get_forecast(h).conf_int(alpha=0.05) даёт интервалы, res.forecast(h) — только точки; интервалы предполагают нормальность остатков — ещё одна причина проверять Q-Q. Ошибка прогноза оценивается на отложенных данных (см. 6.2–6.3), а не по ширине интервала.

Кросс-валидацию хотелось бы использовать и здесь, но «в лоб», как в машинном обучении, не получится: стандартные k-fold перемешивают данные, и тестовая выборка содержит точки из прошлого обучающей — это утечка: модель при обучении «видит будущее». Правильно: тест всегда хронологически позже обучающей выборки, без исключений. Тогда на обучающей части строим ACF/PACF, подбираем параметры и гиперпараметры, а на тестовой — оцениваем итоговое качество модели, которая в подборе не участвовала; кросс-валидация нужна, потому что разбиений много, модели по ним разные, и усреднение нивелирует эти нюансы.

На пальцах

Перемешать временной ряд — как готовиться к экзамену по ответам, среди которых уже лежат завтрашние билеты: соседние точки сильно коррелированы, и, зная $X_{t-1}$ и $X_{t+1}$, «предсказать» $X_t$ несложно; оценка качества получится нечестно оптимистичной. Единственное честное правило — обучение только на прошлом, проверка только на будущем.

Два подхода к разбиению. Второй — сдвигающееся вперёд фиксированное окно: обучающая выборка постоянного размера, но часть данных просто выбрасывается. Когда что: если данных мало — расширяющееся окно, чтобы по максимуму использовать накопленную историю; если нужно моделировать реальный процесс, где модель переобучается каждый день на свежих данных (например, в финансах), — скользящее окно. На пальцах

Expanding — «учусь на всём, что было»; rolling — «учусь на последних $N$ днях, как это будет в проде». Первый даёт стабильнее оценки коэффициентов, второй честнее показывает, как модель живёт при дрейфе данных. В песочнице для ARIMA(1,1,1) RMSE на горизонте 12 по пяти фолдам: expanding $5{,}32$, rolling с окном 200 — $5{,}40$ — почти одинаково, потому что ряд стационарен в приростах и дрейфа нет.

Вне слайдов

sklearn.model_selection.TimeSeriesSplit(n_splits=5, max_train_size=None, test_size=None, gap=0) (sklearn 1.8.0, проверено): max_train_size превращает расширяющееся окно в скользящее; test_size — длина теста = горизонт; gap — зазор между обучением и тестом (если признаки используют будущие лаги). Сам объект только выдаёт индексы — модель ARIMA на каждом фолде переобучается вручную.

§7. VAR и смежные модели (сл. 22–27)

7.1. Мотивация: почему одного ряда недостаточно (сл. 22)

Пример: температура воздуха и потребление электроэнергии взаимно влияют друг на друга — рост температуры увеличивает нагрузку, высокая нагрузка влияет на прогнозы управления сетью. ARIMA на каждый ряд отдельно игнорирует эту связь. Идея VAR: векторное обобщение AR — моделировать все ряды совместно, используя взаимные лаги как предикторы (сл. 22).

Из записи лекции [1:20:29–1:23:46]

Всё до этого — одномерные модели: один ряд, одна модель. А если рядов несколько и они влияют друг на друга? Когда жарко, кондиционеры потребляют больше; когда потребление высокое, энергосистема нагружена, и это влияет на прогнозы управления сетью — связь двусторонняя. ARIMA на каждый ряд по отдельности эту связь игнорирует — теряем информацию, прогноз хуже. Идея — векторная авторегрессия VAR (не путать с обозначением дисперсии $\operatorname{Var}$): моделировать все ряды совместно.

На пальцах

Два ряда, влияющих друг на друга, — как два маятника на одной перекладине: качание одного передаётся другому. Описывая каждый отдельно, мы приписываем передачу «шуму». VAR добавляет в уравнение каждого ряда лаги всех рядов — и «шум» превращается в объяснённую связь.

7.2. VAR(p): матричная запись и стационарность (сл. 23)

Уравнение VAR($p$): $$Y_t=A_1Y_{t-1}+\dots+A_pY_{t-p}+\varepsilon_t,\qquad Y_t\in\mathbb{R}^K,\quad A_i\in\mathbb{R}^{K\times K},\quad \varepsilon_t\sim\mathcal{N}(0,\Sigma).$$ Аналогия: AR($p$) с матрицами вместо скаляров. Раскрытие для $K=2$, $p=1$ — где живёт перекрёстное влияние: $$\begin{pmatrix}X_t\\ Y_t\end{pmatrix}=\begin{pmatrix}a_{11} & a_{12}\\ a_{21} & a_{22}\end{pmatrix}\begin{pmatrix}X_{t-1}\\ Y_{t-1}\end{pmatrix}+\begin{pmatrix}\varepsilon^X_t\\ \varepsilon^Y_t\end{pmatrix},$$ $a_{12}$ — влияние $Y_{t-1}$ на $X_t$; $a_{21}$ — влияние $X_{t-1}$ на $Y_t$. Условие стационарности: корни $\det(I-A_1z-\dots-A_pz^p)=0$ лежат вне единичного круга — та же логика, что для AR (сл. 23).

Из записи лекции [1:23:46–1:28:08]

Идея та же, что в одномерной AR($p$): текущий вектор $Y_t$ — взвешенная сумма $p$ прошлых векторов плюс векторный белый шум; разница в том, что $X$ были элементами выборки, а $Y_t$ — векторы, и коэффициенты $A_i$ — уже не скаляры $\varphi$, а матрицы (лектор оговаривается «тоже вектор», затем — «матрица»). Для двух рядов и одного лага — матрица $2\times2$: диагональные элементы $a_{11}$, $a_{22}$ — авторегрессионные коэффициенты каждого ряда «сам на себя»; внедиагональные $a_{12}$, $a_{21}$ — перекрёстное влияние: $a_{12}$ — как $Y_{t-1}$ влияет на $X_t$, $a_{21}$ — как $X_{t-1}$ влияет на $Y_t$. (Оговорка лектора: на слайде $Y_t$ в общей формуле — вектор, а в раскрытии $X$ и $Y$ — скалярные ряды, обозначения совпали неудачно.) Для трёх рядов — матрица $3\times3$ и больше внедиагональных элементов; именно в них вся информация о взаимосвязях. Стационарность — та же логика: корни характеристического полинома вне единичного круга, только теперь это определитель матричного полинома.

На пальцах

Матрица $A_1$ — «таблица влияний»: строка — кто получает влияние, столбец — от кого. Диагональ — инерция каждого ряда, внедиагональ — передача между рядами; нули вне диагонали означают, что ряды можно моделировать порознь. В песочнике для $A_1=\begin{pmatrix}0{,}5 & 0{,}3\\ 0 & 0{,}6\end{pmatrix}$ (второй ряд влияет на первый, но не наоборот) VAR по BIC выбрал $p=1$ и восстановил $\begin{pmatrix}0{,}49 & 0{,}27\\ 0{,}02 & 0{,}60\end{pmatrix}$.

7.3. Оценка VAR и выбор порядка (сл. 24)

Ключевой факт: OLS по уравнению. Каждое уравнение VAR — отдельная линейная регрессия на лаги всех переменных ⇒ МНК применяется к каждому уравнению независимо. Почему работает: $\varepsilon_t$ некоррелированы с регрессорами $Y_{t-1},\dots,Y_{t-p}$. Выбор порядка $p$: AIC/BIC — те же формулы, что для ARIMA, но $\ell$ — совместное лог-правдоподобие всех $K$ уравнений. Практика: число параметров растёт как $K^2p$ — при $K=5$, $p=4$ это уже 100 параметров; выбирайте минимально достаточный порядок по BIC (сл. 24).

Из записи лекции [1:28:08–1:31:06]

Хорошая новость: оценивать VAR не так уж сложно. Каждое уравнение — отдельная линейная регрессия: уравнение для $X_t$ — регрессия на лаги всех переменных, не только $X$, но и $Y$; для второго ряда — то же. Поэтому можно применять МНК (ordinary least squares) к каждому уравнению независимо; работает, потому что шумы $\varepsilon_t$ некоррелированы с регрессорами — стандартное условие МНК здесь выполнено. Порядок $p$ — по тем же AIC/BIC, только лог-правдоподобие берётся совместно по всем уравнениям. Нюанс: число параметров растёт как $K^2p$, где $K$ — число переменных; при $K=5$ и четырёх лагах — уже 100 параметров; поэтому важно выбирать минимальный достаточный порядок по критериям.

На пальцах

Каждая строка матричного уравнения — обычная регрессия «мой сегодняшний $X$ на вчерашние $X$ и $Y$», и их можно оценивать по очереди, как $K$ отдельных AR-моделей с общими регрессорами. Плата за общность — комбинаторный рост параметров: пять рядов и четыре лага — сто коэффициентов, каждый со своей ошибкой; на коротких рядах это уже переобучение, поэтому BIC и «минимально достаточный $p$».

Вне слайдов

К $K^2p$ добавляются $K$ свободных членов и $K(K+1)/2$ элементов $\Sigma$ (в примере $K=5$, $p=4$: $100+5=105$ коэффициентов регрессии). statsmodels.tsa.api.VAR(Y).fit(maxlags, ic='bic') (проверено: fit(maxlags=None, method='ols', ic=None, trend='c')) выбирает $p$ по критерию; VAR(Y).select_order(maxlags) печатает таблицу AIC/BIC/HQ/FPE по всем $p$. Условие стационарности проверяется res.is_stable() / res.roots.

7.4. Причинность по Грейнджеру (сл. 25)

Определение: $X$ грейнджер-причиняет $Y$, если прошлые значения $X_{t-1},\dots$ улучшают прогноз $Y_t$ при наличии всей прочей информации. $F$-тест — сравниваем два уравнения: $$\text{ограниченное: }Y_t=\sum_{k=1}^{p}\alpha_kY_{t-k}+\varepsilon_t;\qquad \text{неограниченное: }Y_t=\sum_{k=1}^{p}\alpha_kY_{t-k}+\sum_{k=1}^{p}\beta_kX_{t-k}+\varepsilon_t.$$ $H_0$: $\beta_1=\dots=\beta_p=0$. Малое $p$-value ⇒ $X$ предсказывает $Y$. Важно: Granger causality $\ne$ causality — это предиктивная связь, не причинность в философском смысле (сл. 25).

Из записи лекции [1:31:06–1:34:45]

Раз есть перекрёстные влияния, естественный вопрос: влияет ли ряд $X$ на ряд $Y$ вообще, или соответствующие коэффициенты — просто шум? Как в обычной регрессии проверяли значимость коэффициентов. Для этого — причинность по Грейнджеру: сравниваем ограниченное уравнение (без лагов $X$) и неограниченное (с лагами $X$); $F$-тест проверяет $H_0$ «все коэффициенты при лагах $X$ равны нулю»; маленькое $p$ — отвергаем: добавление $X$ статистически улучшает прогноз $Y$, «$Y$ зависит от $X$». Важная оговорка: это не причинность в обычном смысле, а предиктивная связь: прошлые значения $X$ содержат информацию о будущих $Y$, но $X$ не обязательно причина $Y$ — оба могут зависеть от третьей переменной, как при обсуждении корреляции.

На пальцах

Тест Грейнджера отвечает на вопрос «помогает ли знание прошлого $X$ предсказывать $Y$ сверх того, что даёт прошлое самого $Y$» — и только на него. Продажи мороженого «грейнджер-причиняют» число утонувших, потому что оба следуют за температурой. В песочнике: в системе, где $Y_2$ влияет на $Y_1$, а обратно — нет, тест дал $p\lt0{,}0001$ для $Y_2\to Y_1$ и $p=0{,}56$ для $Y_1\to Y_2$.

Вне слайдов

На пальцах

IRF — «щёлкнуть по одной переменной и смотреть, как звенит система»: значимый отклик — долгое звучание, краткосрочный — быстро гаснет. Ортогонализация нужна, потому что шумы разных рядов коррелированы и «чистый щелчок» по одному ряду не наблюдается; Холески приписывает одновременную корреляцию первой переменной в списке, поэтому порядок переменных — это содержательное предположение о том, кто действует «первым» внутри периода.

7.6. VECM vs VAR: когда переключаться (сл. 27)

Коинтеграция: два $I(1)$ ряда, но их линейная комбинация $\beta^{\top}Y_t\sim I(0)$ — стационарна. Уравнение VECM: $$\Delta Y_t=\underbrace{\alpha\,\beta^{\top}Y_{t-1}}_{\text{коррекция ошибки}}+\Gamma_1\Delta Y_{t-1}+\dots+\varepsilon_t.$$ Практическое правило: VAR $\xrightarrow{\text{тест Йохансена}}$ если коинтеграция найдена ⇒ перейти к VECM (сл. 27).

Из записи лекции [1:37:47–1:42:27]

Последнее понятие — коинтеграция. Два нестационарных ряда, каждый $I(1)$: можно взять первые разности и строить VAR на разностях. Но иногда ряды «движутся вместе»: их линейная комбинация стационарна, хотя каждый по отдельности — нет. Пример: цена акции и её фундаментальная стоимость — краткосрочно расходятся, долгосрочно возвращаются друг к другу. VAR на разностях эту долгосрочную связь потеряет; VECM сохраняет её через член коррекции ошибки, который «тянет систему обратно к долгосрочному равновесию». Наличие коинтеграции проверяет тест Йохансена; алгоритм: строим VAR, проводим тест; коинтеграция найдена — переходим к VECM, нет — достаточно VAR. Многомерные ряды — отдельная большая тема, отдельной лекции по ним, скорее всего, не будет; VAR затронут как самый используемый метод.

На пальцах

Коинтеграция — «пьяный и его собака на поводке»: каждый блуждает, но расстояние между ними ограничено. VECM моделирует и шаги (разности), и натяжение поводка ($\alpha\beta^{\top}Y_{t-1}$): чем дальше разошлись, тем сильнее тянет обратно. В песочнике два ряда с общим блужданием ($Y^{(2)}\approx1{,}5Y^{(1)}$): тест Йохансена — статистика $202{,}7$ против критического $15{,}5$ (ранг 1), VECM восстановил $\beta=(1;\,-0{,}666)$ при теоретическом $-1/1{,}5=-0{,}667$.

Раздел 3. Вопросы для подготовки к защите лабораторных (теория)

Формат ответа: сначала тезис (1–2 предложения), затем аргументация от лица студента; ссылки на слайды и таймкоды — для самопроверки.

1. Почему условие стационарности AR формулируется через корни полинома «вне единичного круга», и что происходит на границе?

Тезис: каждый корень $z_i$ задаёт множитель $(1/z_i)^k$, с которым затухает вклад прошлого; при $|z_i|\gt1$ вклады гаснут, на окружности не гаснут (единичный корень, случайное блуждание), внутри — нарастают и процесс «убегает».

Аргументация: для AR(1) $\varphi(z)=1-\varphi_1z$, корень $z=1/\varphi_1$, условие $|\varphi_1|\lt1$ (сл. 4; запись 09:15–11:53) — те же три режима, что на Лекции 1. Для AR($p$) проверяют все корни: у AR(2) с $\varphi_1=0{,}6$, $\varphi_2=0{,}3$ модули $3{,}08$ и $1{,}08$ — стационарна, но близость второго корня к 1 объясняет медленное затухание ACF на сл. 5. Практически: ArmaProcess(...).isstationary или enforce_stationarity=True в ARIMA.

2. Почему AR оценивается замкнутой формулой, а MA — итерационно? Откуда берутся «белые шумы» для оценки MA?

Тезис: регрессоры AR — наблюдаемые лаги ряда, поэтому МНК даёт $\hat\varphi=(X^{\top}X)^{-1}X^{\top}y$; регрессоры MA — ненаблюдаемые прошлые шумы, их приходится восстанавливать рекурсивно внутри ММП, начиная с предположения о нулевых стартовых шумах.

Аргументация (сл. 6, 9; запись 17:32–20:07, 29:44–33:02, вопрос 1:46:00): при гауссовских ошибках МНК совпадает с (условным) ММП. Для MA(1): $\hat\varepsilon_1=X_1$ при $\varepsilon_0=0$, $\hat\varepsilon_2=X_2-\theta\hat\varepsilon_1$, … — при пробном $\theta$ разматываем цепочку, считаем правдоподобие, корректируем $\theta$. Влияние стартового предположения затухает при $|\theta|\lt1$ (обратимость), поэтому на длинных рядах оно несущественно; точные реализации используют фильтр Калмана. Следствие: при больших $q$ оценка заметно медленнее.

3. Зачем нужна ARMA, если любой стационарный ряд можно описать AR достаточно высокого порядка?

Тезис: ради экономии параметров — ARMA(1,1) с двумя коэффициентами часто подгоняет данные не хуже AR(6) с шестью; полюс $\varphi$ задаёт затухание, ноль $\theta$ — форму начального отклика.

Аргументация (сл. 10; запись 34:29–37:08): меньше параметров — меньше дисперсия оценок и лучше прогноз при том же правдоподобии; критерии это фиксируют (в песочнице для синтетической ARMA(1,1): AIC/BIC $1697/1711$ против $1706/1737$ у AR(6)). Обратимая ARMA эквивалентна AR($\infty$) — AR высокого порядка лишь усекает этот ряд.

4. Как по ACF/PACF выдвигается гипотеза о модели и почему её надо подтверждать AIC/BIC?

Тезис: обрыв PACF на $p$ — AR($p$), обрыв ACF на $q$ — MA($q$), оба затухают — ARMA; но на реальных данных «обрыв» зашумлён (столбики у полосы, случайные выбросы), поэтому коррелограмма даёт гипотезу, а критерии по сетке $(p,q)$ и диагностика остатков — подтверждение.

Аргументация (сл. 5, 8, 11; запись 13:10–17:32, 28:43–29:44, 38:36–42:32): полоса $\pm1{,}96/\sqrt n$ означает 5 % ложных выходов даже у белого шума; одиночный столбик у линии — погрешность, растущая по модулю серия — структура. Идентификация возможна только для стационарного ряда — иначе сначала $d$.

5. Как определить $d$: что проверяют ADF и KPSS и что делать при противоречии?

Тезис: ADF ($H_0$ — единичный корень) и KPSS ($H_0$ — стационарность) имеют противоположные нулевые гипотезы; согласный вывод обоих — уверенный; противоречие указывает на структурный сдвиг или нелинейность, где дифференцирование не поможет.

Аргументация (сл. 12–13; запись 42:32–50:44): $\Delta$ убирает линейный тренд и единичный корень; $I(d)$ — стационарен после $d$ разностей; тесты повторяют на разности. Пример из песочницы: уровень — ADF $p=0{,}66$/KPSS $0{,}01$, разность — ADF $p\lt0{,}001$/KPSS $0{,}10$. Готовые реализации — adfuller, kpss с выбором regression='c'|'ct'.

6. Как распознать передифференцирование и почему ACF на лаге 1 становится $\approx-0{,}5$?

Тезис: если после $d$ разностей получился белый шум, ещё одна разность даёт $\varepsilon_t-\varepsilon_{t-1}$ — MA(1) с $\theta=-1$, у которого $\rho_1=-1/2$ и потеряна обратимость; отсюда правило «$d=1$ обычно, $d=2$ только с обоснованием».

Аргументация (сл. 14; запись 50:44–53:34): $\rho_1=\theta/(1+\theta^2)=-0{,}5$ при $\theta=-1$; проверено на блуждании: ACF($\Delta$)$[1]=0{,}006$, ACF($\Delta^2$)$[1]=-0{,}505$. Симптомы в оценённой модели — $\hat\theta\approx-1$ и упирание в границу обратимости; дисперсия приростов растёт вдвое, прогноз не улучшается.

7. Что должны удовлетворять остатки хорошей модели, и как читать тест Льюнга–Бокса и Q-Q plot?

Тезис: остатки — белый шум: некоррелированы (Льюнг–Бокс, $H_0$ — некоррелированы, $p\lt0{,}05$ ⇒ модель недоспецифицирована) и нормальны (Q-Q на диагонали, симметричная гистограмма); auto_arima этот шаг не делает, поэтому диагностика обязательна.

Аргументация (сл. 16–17; запись 1:00:24–1:07:35): $Q=n(n+2)\sum\hat\rho_k^2/(n-k)$ суммирует квадраты выборочных автокорреляций; для остатков ARMA($p,q$) степеней свободы $m-p-q$ (model_df=p+q). Загнутые хвосты Q-Q и узкая гистограмма без хвостов — признаки выбросов/ненормальности, которые портят доверительные интервалы прогноза даже при хорошем RMSE.

8. AIC или BIC — что выбрать и почему BIC «строже при $n\gt7$»?

Тезис: оба — $-2\ell$ плюс штраф; штраф AIC $2k$, BIC $k\ln n$, и $\ln n\gt2$ при $n\ge8$ ($e^2\approx7{,}39$), поэтому на больших выборках BIC жёстче и предпочитает простые модели; совпали — доверяем, разошлись — обосновываем содержательно.

Аргументация (сл. 18; запись 1:07:35–1:10:13): в примере песочницы AIC выбрал $(3,0)$, BIC — $(1,1)$ при истинном $(1,1)$ — экономная модель выиграла по содержанию. Сравнивать критерии допустимо лишь при одном $d$ и одном ряде.

9. Почему доверительный интервал прогноза расширяется с горизонтом, и к чему сходится точечный прогноз ARIMA?

Тезис: прогноз — условное ожидание $\mathbb{E}[X_{T+h}\mid X_T,\dots]$; каждый шаг вперёд добавляет дисперсию нового толчка, поэтому конус растёт; у $I(1)$ прогноз сходится к константе (у блуждания — к последнему значению), у $I(2)$ — к линейному тренду.

Аргументация (сл. 19; запись 1:10:13–1:13:13): AR-часть забывает последние наблюдения как $\varphi^h$; накопленная дисперсия блуждания растёт как $\sigma^2h$. В песочнике полуширина 95 % ДИ ARIMA(1,1,1): $1{,}9\to12{,}7\to21{,}1\to32{,}1$ при $h=1,6,12,24$. «Это нормально» — не дефект модели, а честная неопределённость.

10. Почему k-fold кросс-валидация неприменима к временным рядам и чем отличаются expanding и rolling window?

Тезис: k-fold перемешивает время — тест содержит точки из прошлого обучающей выборки, модель «видит будущее» (утечка); правильно — тест всегда позже train; expanding (TimeSeriesSplit) наращивает обучение и годится при малых данных, rolling с фиксированным окном имитирует ежедневное переобучение в продакшене.

Аргументация (сл. 20–21; запись 1:13:13–1:20:29): соседние точки коррелированы, поэтому интерполяция внутрь ряда нечестно легка. TimeSeriesSplit(n_splits, test_size, max_train_size, gap): max_train_size даёт rolling. Итоговое качество оценивается на тестовых фолдах, не участвовавших в подборе $(p,d,q)$.

11. Где в VAR «живёт» взаимосвязь рядов, почему VAR оценивается обычным МНК и чем опасен рост порядка?

Тезис: во внедиагональных элементах матриц $A_i$ ($a_{12}$ — влияние $Y_{t-1}$ на $X_t$); каждое уравнение — регрессия на лаги всех переменных с регрессорами, некоррелированными с $\varepsilon_t$, поэтому МНК применим поуравненно; параметров $K^2p$ — при $K=5$, $p=4$ уже 100, поэтому $p$ выбирают минимально достаточным по BIC.

Аргументация (сл. 23–24; запись 1:23:46–1:31:06): стационарность — корни $\det(I-A_1z-\dots)=0$ вне круга; $\ell$ для критериев — совместное по $K$ уравнениям. В песочнике VAR восстановил матрицу с нулевым обратным влиянием как $0{,}02$ и выбрал $p=1$.

12. Что означает «$X$ грейнджер-причиняет $Y$», как читать IRF и когда VAR заменяют на VECM?

Тезис: Грейнджер — предиктивная связь ($F$-тест на нулевые $\beta_k$ при лагах $X$), не причинность; IRF — отклик $Y_{t+h}$ на единичный шок $\varepsilon^X_t$, значим, пока CI не включает 0, и зависит от порядка переменных при ортогонализации Холески; если $I(1)$-ряды коинтегрированы (тест Йохансена), VAR на разностях теряет долгосрочную связь — нужен VECM с членом коррекции ошибки $\alpha\beta^{\top}Y_{t-1}$.

Аргументация (сл. 25–27; запись 1:31:06–1:42:27): общая скрытая причина даёт «причинность» в обе стороны; порядок переменных — допущение о том, кто реагирует первым внутри периода. Песочница: Грейнджер $p\lt10^{-4}$ для истинного направления и $0{,}56$ для обратного; Йохансен trace $202{,}7$ против $15{,}5$, VECM $\beta=(1;-0{,}666)$ при истинном $-0{,}667$.

4.4. Чего в Лекции 3 нет / ловушки, которые стоит проверить

  • Сезонность (SARIMA) в лекции не рассматривается, хотя почасовые/суточные данные её содержат; в ARIMA есть seasonal_order=(P,D,Q,s), в auto_arima — seasonal=True, m=s. Без учёта сезонности остатки покажут пики ACF на кратных $s$ лагах.
  • Дрейф и тренд: «$I(1)$ сходится к константе» верно без дрейфа; с trend='t' прогноз — прямая.
  • Степени свободы Льюнга–Бокса: для остатков указывать model_df=p+q; на слайде $\chi^2(m)$ — для сырого ряда.
  • МНК = ММП — точно для условного правдоподобия; ARIMA считает точное, оценки чуть различаются на коротких рядах.
  • Сравнение критериев только при одинаковом $d$ и одном ряде; после дифференцирования выборка другая.
  • Передифференцирование проявляется и как $\hat\theta\to-1$ с упиранием в границу обратимости.
  • VAR: к $K^2p$ добавляются свободные члены; IRF зависят от порядка столбцов; Грейнджер предполагает стационарность.
  • Из шаблона курса в этой лекции нет HMM-тематики (BIC для числа состояний, рестарты EM) — это Лекция 2; ACF/PACF определены в Лекции 1.

4.5. Скелет решения ЛР (исполнен в песочнице без ошибок)

import itertools, numpy as np
from statsmodels.tsa.arima_process import ArmaProcess
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.stattools import adfuller, kpss, acf, pacf
from statsmodels.stats.diagnostic import acorr_ljungbox
from statsmodels.tsa.api import VAR
from sklearn.model_selection import TimeSeriesSplit
import warnings; warnings.filterwarnings("ignore")

# ---------- 1. Синтетический нестационарный ряд: ARIMA(1,1,1) ----------
rng = np.random.default_rng(7)
u = ArmaProcess(ar=[1, -0.6], ma=[1, 0.4]).generate_sample(500, distrvs=rng.standard_normal, burnin=200)
y = 50 + np.cumsum(u)                     # уровень = кумулятивная сумма ARMA(1,1) => I(1)

# ---------- 2. Стационарность: ADF (H0: единичный корень) + KPSS (H0: стационарен), сл. 13 ----------
def stationarity(x, name):
    p_adf = adfuller(x, autolag="AIC")[1]; p_kpss = kpss(x, nlags="auto")[1]
    verdict = "стационарен" if (p_adf < 0.05 and p_kpss > 0.05) else ("нестационарен" if (p_adf >= 0.05 and p_kpss <= 0.05) else "противоречие")
    print(f"{name}: ADF p={p_adf:.3f}, KPSS p={p_kpss:.3f} -> {verdict}")
stationarity(y, "уровень"); d1 = np.diff(y); stationarity(d1, "первая разность")
print("ACF Δy (лаги 1-3):", acf(d1, nlags=3)[1:].round(3), " PACF:", pacf(d1, nlags=3)[1:].round(3))
rw = np.cumsum(rng.standard_normal(3000))            # чистое случайное блуждание: одной разности достаточно
print("Случайное блуждание: ACF(Δ)[1] =", acf(np.diff(rw), nlags=1)[1].round(3),
      " ACF(Δ²)[1] =", acf(np.diff(rw, 2), nlags=1)[1].round(3), "(≈ -0.5 => передифференцирование, сл. 14)")

# ---------- 3. Сетка (p,q) по AIC/BIC при d=1 (сл. 11, 18) ----------
grid = {}
for p, q in itertools.product(range(4), range(4)):
    try:
        r = ARIMA(y, order=(p, 1, q)).fit(); grid[(p, q)] = (r.aic, r.bic)
    except Exception:
        pass
best_aic = min(grid, key=lambda k: grid[k][0]); best_bic = min(grid, key=lambda k: grid[k][1])
print(f"AIC выбирает (p,q)={best_aic}, BIC выбирает {best_bic}")
order = (best_bic[0], 1, best_bic[1]); model = ARIMA(y, order=order).fit()
print(f"ARIMA{order}: params={model.params.round(3)}  AIC={model.aic:.1f} BIC={model.bic:.1f}")

# ---------- 4. Диагностика остатков: Льюнг–Бокс (H0: некоррелированы), сл. 17 ----------
lb = acorr_ljungbox(model.resid[1:], lags=[10, 20], model_df=order[0] + order[2], return_df=True)
print("Ljung-Box p-value (лаги 10, 20):", lb["lb_pvalue"].round(3).tolist(), "-> остатки", "ок" if (lb["lb_pvalue"] > 0.05).all() else "коррелированы")

# ---------- 5. Прогноз на h шагов с доверительным интервалом (сл. 19) ----------
fc = model.get_forecast(24); ci = fc.conf_int(alpha=0.05)
print("полуширина 95% ДИ при h=1,6,12,24:", ((ci[:, 1] - ci[:, 0]) / 2)[[0, 5, 11, 23]].round(2), "(конус расширяется)")

# ---------- 6. Кросс-валидация для рядов: expanding vs rolling (сл. 20-21) ----------
def cv_rmse(splitter, h=12):
    errs = []
    for tr, te in splitter.split(y):
        m = ARIMA(y[tr], order=order).fit(); f = m.forecast(h)
        errs.append(np.sqrt(np.mean((y[te[:h]] - f) ** 2)))
    return np.mean(errs)
print("RMSE(h=12) expanding:", round(cv_rmse(TimeSeriesSplit(n_splits=5, test_size=12)), 2),
      "| rolling(max_train_size=200):", round(cv_rmse(TimeSeriesSplit(n_splits=5, test_size=12, max_train_size=200)), 2))

# ---------- 7. VAR на двух рядах + причинность по Грейнджеру (сл. 23-25) ----------
A1 = np.array([[0.5, 0.3], [0.0, 0.6]]); Y = np.zeros((800, 2))
for t in range(1, 800): Y[t] = A1 @ Y[t - 1] + rng.standard_normal(2) * 0.5   # y2 влияет на y1, но не наоборот
res = VAR(Y).fit(maxlags=4, ic="bic")
print(f"VAR: выбран p={res.k_ar}; Granger y2->y1 p={res.test_causality('y1', ['y2'], kind='f').pvalue:.4f}, "
      f"y1->y2 p={res.test_causality('y2', ['y1'], kind='f').pvalue:.3f}")

Результат прогона (seed 7): уровень — ADF $p=0{,}655$, KPSS $p=0{,}010$ (нестационарен); первая разность — ADF $p\lt0{,}001$, KPSS $p=0{,}100$ (стационарна); ACF/PACF разности $(0{,}75;\,0{,}43;\,0{,}24)$ / $(0{,}75;\,-0{,}32;\,0{,}14)$ — оба затухают ⇒ ARMA; для чистого блуждания ACF($\Delta^2$)$[1]=-0{,}505$; AIC выбрал $(3,0)$, BIC — $(1,1)$; ARIMA(1,1,1): $\hat\varphi=0{,}61$, $\hat\theta=0{,}45$ (истинные $0{,}6$ и $0{,}4$); Льюнг–Бокс $p=0{,}81/0{,}95$ — остатки в порядке; полуширина 95 % ДИ $1{,}9\to32{,}1$ при $h=1\to24$; RMSE($h=12$) expanding $5{,}32$, rolling $5{,}40$; VAR выбрал $p=1$, Грейнджер $y_2\to y_1$ $p\lt10^{-4}$, обратно $p=0{,}088$.
