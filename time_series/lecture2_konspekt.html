§1. Марковские цепи с дискретным временем (сл. 2–6)

1.1. Мотивация: наблюдаемые и скрытые режимы (сл. 2)

Марковские цепи: система переходит между наблюдаемыми режимами. Примеры: норма / деградация / отказ оборудования; бычий / медвежий / боковой рынок.

Скрытые МЦ (HMM): режим не наблюдается напрямую — виден только зашумлённый сигнал. Примеры: доходности как проекция волатильностного режима; ЭКГ как проекция ритма сердца (сл. 2).

Пример 1 — турбина на заводе. Три режима: норма, начало деградации, критический износ (отказ). Режим меняется случайно, и то, в каком состоянии турбина окажется завтра, зависит только от сегодняшнего состояния, а не от всей истории. Из нормы нельзя перейти сразу в отказ — только через деградацию; из отказа в норму — после ремонта; после ремонта завтрашнее состояние не зависит от вчерашнего. Это и есть марковская цепь.

Пример 2 — датчик на той же турбине. Датчик шумит; сами режимы мы не видим, видим только зашумлённые показания. То же с ЭКГ: сердце в синусовом ритме или в тахикардии, а сигнал на ленте кардиографа — «шумная проекция» этого скрытого состояния. Это уже не марковская цепь, а скрытая марковская модель; в презентации используется английская аббревиатура HMM как устоявшаяся.

План по словам лектора: марковские цепи → переход от дискретного времени к непрерывному («есть нюансы отличия») → скрытые марковские модели → примеры.

На пальцах

Марковская цепь — «настольная игра»: чтобы знать, куда можно попасть следующим ходом, достаточно знать клетку, на которой стоишь; как ты на неё пришёл — неважно. Скрытая марковская модель — та же игра, но фишку от вас спрятали, и вы видите только зашумлённые подсказки о том, где она (например, звук, который зависит от клетки). Задача — по подсказкам восстановить путь фишки.

1.2. Марковское свойство (сл. 3)

Определение (дискретное время): $$P(X_{t+1}=j\mid X_t=i,\,X_{t-1},\dots,X_0)=P(X_{t+1}=j\mid X_t=i).$$

Три важных момента (сл. 3): (1) вся история сжата в $X_t$ — это предположение о структуре зависимости, не о её отсутствии; (2) МЦ может порождать долгосрочные корреляции (через $A^n$) — механизм просто компактный; (3) МЦ порядка $k$ сводится к МЦ порядка 1 расширением пространства состояний.

Формула читается так: вероятность следующего состояния при условии, что известны все предыдущие, начиная с нулевого, равна условной вероятности при известном только текущем состоянии — более ранние состояния на следующее не влияют.

Два распространённых заблуждения. Первое: «марковская цепь — процесс без памяти». Это неправда: вся память о прошлом сжата в текущем состоянии; если состояние определено достаточно подробно, история в нём уже закодирована. Это предположение о структуре зависимости, а не об её отсутствии. Второе: «раз нет долгосрочной памяти, нет и долгосрочных корреляций». Тоже неправда: степень матрицы $A^n$ кодирует корреляции на горизонте $n$, и затухание там может быть довольно медленным.

Таблица классификации: сегодня — дискретное время и дискретное пространство состояний (классические цепи Маркова); позже — непрерывное время (CTMC, continuous-time Markov chain). Непрерывные состояния в непрерывном времени приводят к стохастическим дифференциальным уравнениям — «одна из самых сложных областей математики», в курсе не рассматривается.

На пальцах

«Память сжата в состоянии»: у шахматной позиции нет истории, но она полностью определяет, какие ходы возможны дальше. Если «состояния» выбраны слишком грубо (например, только «рынок растёт / падает»), марковость может нарушаться — тогда состояние укрупняют: третий пункт слайда говорит, что цепь, помнящая $k$ шагов, превращается в марковскую цепь первого порядка, если состоянием объявить весь набор последних $k$ значений (пар, троек и т. д.).

Вне слайдов

Как именно $A^n$ порождает корреляции: для эргодической цепи $\operatorname{Cov}(f(X_t),g(X_{t+n}))$ убывает как $|\lambda_2|^n$, где $\lambda_2$ — второе по модулю собственное число $A$. У матрицы рынка со сл. 4 собственные числа $1;\,0{,}6;\,0{,}4$ (посчитано в песочнице), поэтому корреляции затухают как $0{,}6^n$; при $\lambda_2$, близком к 1, память «долгая», хотя цепь по-прежнему марковская.

1.3. Переходная матрица и многошаговые переходы (сл. 4)

Матрица переходов $A\in\mathbb{R}^{N\times N}$: $$a_{ij}=P(X_{t+1}=j\mid X_t=i),\qquad a_{ij}\ge0,\qquad \sum_j a_{ij}=1$$ — строчно-стохастическая. Многошаговый переход: $$\pi_{t+n}=\pi_t A^n,\qquad (A^n)_{ij}=P(X_{t+n}=j\mid X_t=i).$$

Пример (рынок, $N=3$): $$A=\begin{pmatrix}0{,}8 & 0{,}1 & 0{,}1\\ 0{,}2 & 0{,}7 & 0{,}1\\ 0{,}3 & 0{,}2 & 0{,}5\end{pmatrix},$$ $(A^2)_{12}$ — вероятность оказаться в «медвежьем» режиме через два дня, если сейчас «бычий» (сл. 4).

Пример из финансов: состояния — динамика рынка (акции, облигации). Бычий рынок — устойчивый рост цен и позитивные ожидания; медвежий — устойчивое снижение и преобладание пессимизма; боковой — нет явного тренда, цены колеблются в диапазоне. Внутри дня бывают все три фазы; день классифицируют по преобладающему режиму.

$a_{ij}$ — вероятность перейти из состояния $i$ в состояние $j$ на следующем шаге; все $a_{ij}\ge0$, сумма по строке равна единице — такая матрица называется строчно-стохастической.

Что будет через два шага? Из $i$ в $j$ можно попасть по-разному, через разные промежуточные состояния $k$ (из бычьего в боковой — через медвежий или оставшись бычьим на день); суммируем по всем $k$ — это формула полной вероятности, она и даёт $A^2$. Применив её ещё раз — три шага, $n$ раз — $A^n$. Вариантов пути с ростом числа шагов становится всё больше; матрица считает их все сразу. Индексы: бычий — 1, медвежий — 2, поэтому $(A^2)_{12}$ — «через два дня в медвежьем, если сейчас бычий».

На пальцах

Строка матрицы — «меню» из текущего состояния: строка «бычий» говорит: с вероятностью 0,8 останемся бычьими, по 0,1 — уйдём в медвежий или боковой. Столбец же — «откуда можно прийти». Умножение $\pi_t A$ — это «перераспределение массы»: если сегодня 100 % массы в «бычьем», завтра $0{,}8$ останется, $0{,}1$ перетечёт в «медвежий», $0{,}1$ — в «боковой».

Считаем $(A^2)_{12}$ руками: три маршрута за два дня из Б в М — Б→Б→М: $0{,}8\cdot0{,}1=0{,}08$; Б→М→М: $0{,}1\cdot0{,}7=0{,}07$; Б→Бок→М: $0{,}1\cdot0{,}2=0{,}02$. Сумма $0{,}17$ — ровно то число, что стоит в тепловой карте $A^2$ на сл. 5.

1.4. Стационарное распределение и теорема эргодичности (сл. 5)

Определение. $$\pi A=\pi,\qquad \sum_i\pi_i=1,\qquad \pi_i\ge0$$ — левый собственный вектор $A$ при $\lambda=1$ (теорема Перрона–Фробениуса).

Теорема эргодичности (б/д). Для неприводимой апериодической МЦ: (1) $\pi$ существует и единственно; (2) $\lim_{n\to\infty}(A^n)_{ij}=\pi_j$ не зависит от $i$; (3) временное среднее = ансамблевое. Условия: неприводимость + апериодичность. Нахождение: np.linalg.eig(A.T); $\pi_i=1/\mathbb{E}[T_i]$, $T_i$ — время возврата (сл. 5).

Вопрос: что будет с системой в долгосрочной перспективе, если «гонять» цепь очень долго? На тепловой карте при $n=1$ все строки разные, при $n=5$ строки становятся похожими, при $n=50$ — одинаковыми. Это и есть стационарное распределение $\pi$: вектор, к которому сходятся все строки $A^n$ при $n\to\infty$. Математически — вектор-строка, такая что $\pi A=\pi$: если система уже в этом распределении, она в нём и остаётся; это задача о левом собственном векторе при собственном значении 1.

Когда это выполняется — теорема эргодичности для марковских цепей (свойство эргодичности обсуждалось в прошлой лекции): для неприводимой апериодической цепи стационарное распределение единственно и достигается из любого начального состояния. Неприводимость — из любого состояния можно добраться до любого другого; апериодичность — нет циклической структуры. Ещё одна интерпретация, возможно более понятная: $\pi_i=1/\mathbb{E}[T_i]$, где $T_i$ — среднее время возврата в состояние $i$: если система проводит в состоянии много времени, вероятность этого состояния высока. Это и есть эргодичность — временное среднее равно ансамблевому.

На пальцах

Стационарное распределение — «доля времени, которую цепь проводит в каждом состоянии в долгой перспективе»: рынок из примера в 54 % дней бычий, в 29 % — медвежий, в 17 % — боковой, с какого бы дня мы ни начали считать. Тепловая карта показывает, что через 10 шагов цепь «забыла», откуда стартовала. Неприводимость — «нет закрытых комнат» (из любого состояния есть путь в любое); апериодичность — «нет строгого расписания» (цепь не обязана возвращаться ровно через 2, 4, 6 шагов, как маятник). Если хоть одно условие нарушено, предел строк может не существовать или зависеть от старта.

Связь $\pi_i=1/\mathbb{E}[T_i]$: если в состояние возвращаешься в среднем раз в 6 шагов, значит, находишься в нём примерно $1/6$ времени. Для матрицы рынка средние времена возврата $1{,}85$, $3{,}43$ и $6{,}00$ шагов (посчитано в песочнице) — обратные величины дают ровно $0{,}542$, $0{,}292$, $0{,}167$.

Вне слайдов

Как считать $\pi$ на практике: w, v = np.linalg.eig(A.T), взять столбец $v$, соответствующий собственному числу, ближайшему к 1, и нормировать на сумму (для матрицы сл. 4 получается $(0{,}542;\,0{,}292;\,0{,}167)$, проверено). Альтернатива — решить линейную систему $\pi(A-I)=0$ с заменой одного уравнения на $\sum\pi_i=1$, либо просто возвести $A$ в большую степень. Скорость сходимости $A^n\to\mathbf{1}\pi$ определяется $|\lambda_2|$: здесь $0{,}6$, поэтому к $n=10$ ошибка порядка $0{,}6^{10}\approx0{,}006$ — согласуется с картой. Теорема Перрона–Фробениуса гарантирует, что у неотрицательной неприводимой матрицы максимальное по модулю собственное число вещественно, положительно и имеет положительный собственный вектор; для стохастической матрицы это число равно 1.

1.5. Классификация состояний; надёжность (сл. 6)

Вероятность возврата: $$f_i=P(\exists\,t\ge1:\ X_t=i\mid X_0=i).$$

  • Возвратное: $f_i=1$. Положительно возвратное: $\mathbb{E}[T_i]\lt\infty$; тогда $\pi_i=1/\mathbb{E}[T_i]$.
  • Несущественное: $f_i\lt1$ — цепь уходит навсегда.
  • Поглощающее: $a_{ii}=1$.

Периодичность: $d(i)=\gcd\{n\ge1:\ p^{(n)}_{ii}\gt0\}$. При $d(i)\gt1$ предела $\lim_n(A^n)_{ij}$ не существует (среднее Чезаро сходится).

Надёжность: поглощающее = отказ; $$\mathrm{MTTF}=e_0^{\top}(I-Q)^{-1}\mathbf{1},$$ где $Q$ — подматрица несущественных состояний (сл. 6).

Отказ — особое: попав в него, система сама из него не выходит (если не рассматривать быстрый ремонт); нужно внешнее воздействие — починить турбину. Такое состояние называется поглощающим: оно «поглотило» систему.

Общая формулировка: $f_i$ — вероятность когда-либо вернуться в состояние $i$, выйдя из него. $f_i=1$ — возвратное, система будет возвращаться снова и снова; $f_i\lt1$ — несущественное: рано или поздно цепь уйдёт из него навсегда. Поглощающее — крайний случай возвратного, когда на диагонали $a_{ii}=1$.

Прикладной вывод для теории надёжности: если есть марковская модель с поглощающим состоянием-отказом, стандартная величина — среднее время до отказа, средняя наработка на отказ, MTTF (mean time to failure): среднее время до первого отказа. Вычисляется через фундаментальную матрицу $(I-Q)^{-1}$, где $I$ — единичная матрица, $Q$ — подматрица переходов между несущественными состояниями. Это инструмент оценки надёжности технических и иных систем математическим аппаратом.

Важная связь: если дискретизовать непрерывную цепь с шагом $\Delta t$, получим $A=e^{Q\Delta t}$ — дискретные и непрерывные цепи Маркова — одно семейство моделей.

Задача: по дневным доходностям сказать, в режиме низкой или высокой волатильности рынок сейчас. Казалось бы, достаточно посмотреть на сегодняшнюю доходность. Но $-1\%$ может быть нормой при высокой волатильности и тревожным сигналом при низкой — одно наблюдение ничего не говорит о режиме.

Идея HMM — разделить модель на две компоненты: скрытая цепь $Z_t$, которая управляет режимами и переходит между ними по матрице $A$ (как обычная марковская цепь, только режимы скрыты), и наблюдения $X_t$, которые порождаются из скрытого состояния с шумом и описываются матрицей эмиссий $B$. Наблюдение зависит только от текущего скрытого состояния, а не от истории наблюдений. На графе стрелки в верхнем ряду — динамика скрытой цепи, стрелки вниз — эмиссии; мы видим только $X$.

Замечание лектора: эта модель напоминает ограниченную машину Больцмана (RBM) из курса по нейросетевым архитектурам (Дж. Хинтон, Нобелевская премия по физике 2024) — по его словам, «нейросетевой аналог HMM, с точки зрения математики практически идентичны».

3.2. Формальное определение HMM (сл. 9)

Параметры: $\lambda=(N,M,A,B,\pi_0)$: $N$ — число скрытых состояний $\mathcal{S}=\{s_1,\dots,s_N\}$; $M$ — число символов наблюдений; $A=\{a_{ij}\}$ — матрица переходов, $a_{ij}=P(Z_{t+1}=s_j\mid Z_t=s_i)$; $B=\{b_j(k)\}$ — матрица эмиссий, $b_j(k)=P(X_t=v_k\mid Z_t=s_j)$; $\pi_0$ — начальное распределение.

Ключевые предпосылки: (1) марковское свойство скрытой цепи: $P(Z_{t+1}\mid Z_{1:t})=P(Z_{t+1}\mid Z_t)$; (2) условная независимость наблюдений: $P(X_t\mid Z_{1:T},X_{1:T\setminus t})=P(X_t\mid Z_t)$.

Совместное правдоподобие: $$P(X_{1:T},Z_{1:T}\mid\lambda)=\pi_{0,z_1}\prod_{t=1}^{T-1}a_{z_tz_{t+1}}\prod_{t=1}^{T}b_{z_t}(x_t)\qquad\text{(сл. 9)}.$$

HMM задаётся пятёркой параметров: число скрытых состояний $N$, число символов наблюдений $M$, матрица переходов между скрытыми состояниями $A$ (такая же строчно-стохастическая, как у марковских цепей), матрица эмиссий $B$ — $b_j(k)$ есть вероятность увидеть символ $k$, если скрытое состояние равно $j$, — и начальное распределение $\pi_0$.

Два ключевых предположения: следующее скрытое состояние зависит только от текущего (как в обычной цепи); наблюдение условно независимо при заданных скрытых состояниях — $X_t$ зависит только от $Z_t$ и не зависит от других $X$ и $Z$. На практике второе предположение часто нарушается: в электрокардиографии соседние удары сердца коррелированы даже при фиксированном ритме; но как рабочее приближение HMM работает очень хорошо. Совместное правдоподобие — произведение трёх компонентов: начального распределения, вероятностей переходов и вероятностей эмиссий.

Прямой и обратный ход вместе дают апостериорную вероятность $\gamma_t(i)$: насколько вероятно, что на шаге $t$ система была в состоянии $i$ с учётом всей последовательности наблюдений.

На пальцах

Forward — «подсчёт всех маршрутов с объединением в узлах»: чтобы узнать, сколькими способами (и с каким суммарным весом) можно прийти в клетку $(j,t+1)$, не перечисляем маршруты, а берём уже посчитанные веса всех клеток предыдущего столбца, умножаем на вероятность шага и на «правдоподобие подсказки» $b_j(X_{t+1})$ и складываем. Так за $T$ столбцов веса всех $N^T$ маршрутов оказываются сложенными автоматически. $\alpha$ смотрит только в прошлое («что было до $t$ включительно»), $\beta$ — только в будущее («что будет после $t$»), а $\gamma$ — их произведение, нормированное на сумму по состояниям: это вероятность состояния в момент $t$ с учётом всей записи, прошлого и будущего.

Порядок величин: $\alpha$ убывает с каждым шагом (перемножаем вероятности), поэтому при $T$ в сотни шагов числа уходят к $10^{-100}$ и ниже — отсюда log-space в п. 4.3.

Вне слайдов

Форма записи через логарифмы: $\log\alpha_{t+1}(j)=\log b_j(X_{t+1})+\operatorname{logsumexp}_i\big(\log\alpha_t(i)+\log a_{ij}\big)$, где $\operatorname{logsumexp}(v)=\max v+\log\sum e^{v-\max v}$ (scipy.special.logsumexp) — так исчезает underflow без нормировки. Вторая стандартная техника — масштабирование: на каждом шаге делить $\alpha_t$ на $c_t=\sum_i\alpha_t(i)$ и накапливать $\log P(X\mid\lambda)=\sum_t\log c_t$; $\gamma$ от масштабирования не меняется. В hmmlearn параметр implementation переключает 'log' (по умолчанию) и 'scaling'. Реализация прямого хода в log-space «с нуля» на NumPy совпадает с GaussianHMM.score до $10^{-4}$ (п. 4.5, проверено).

4.3. Задача 2: алгоритм Витерби; MAP по точкам против глобального пути; log-space (сл. 12)

Отличие от Forward: $\sum\to\max$: $$\delta_{t+1}(j)=b_j(X_{t+1})\cdot\max_i\big[\delta_t(i)\,a_{ij}\big],\qquad \psi_{t+1}(j)=\arg\max_i\big[\delta_t(i)\,a_{ij}\big].$$ Восстановление: $z^*_T=\arg\max_i\delta_T(i)$, затем $z^*_t=\psi_{t+1}(z^*_{t+1})$.

MAP vs Витерби (на слайде опечатка «MAR»): $\arg\max_i\gamma_t(i)$ поточечно оптимален, но может дать недопустимую последовательность. Витерби — глобальный оптимум. Log-space: $$\log\delta_{t+1}(j)=\log b_j+\max_i\big[\log\delta_t(i)+\log a_{ij}\big]\qquad\text{(сл. 12)}.$$

Рисунок (сл. 12). Та же решётка $N=2$, $T=4$ с узлами $\delta_t(i)$. Тёмно-синим выделены узлы оптимального пути $\delta_1(1)\to\delta_2(2)\to\delta_3(2)\to\delta_4(1)$; синие стрелки — оптимальный путь, красные пунктирные в обратную сторону — backtracking.
Из записи лекции [52:07–59:16]

Казалось бы, можно взять в каждый момент состояние с максимальной $\gamma_t$ — и готово. Это ошибка, «важная и не очевидная»: такой подход называется MAP-оценкой по точкам; поточечно она оптимальна, но набор состояний может оказаться недопустимым, потому что между некоторыми парами состояний вероятность перехода нулевая, а формула для $\gamma$ этого никак не учитывает. Глобально оптимальный путь ищут иначе — алгоритмом Витерби: та же решётка, только вместо суммирования берём максимум. $\delta_{t}(j)$ — максимальная вероятность любого пути до состояния $j$ в момент $t$; рекуррентная формула — как у прямого хода с заменой суммы на максимум.

Дальше — шаг, который лектор сравнивает с обратным распространением ошибки: backtracking (красные стрелки на схеме). Найдя оптимальное финальное состояние, идём назад по сохранённым указателям $\psi$ — для каждого узла запомнено, из какого предыдущего состояния пришёл максимум $\delta_t(i)a_{ij}$. Синие стрелки — прямой ход, красные — восстановление пути.

При длинных последовательностях произведения вероятностей уходят в машинный ноль: перемножая много чисел меньше единицы, получаем число настолько малое, что точности чисел с плавающей запятой не хватает. Решение — логарифмическое пространство: логарифм превращает произведение в сумму, а сумма гораздо меньше зависит от машинной точности. Формулу просто прологарифмировали: вместо вероятностей — их логарифмы, вместо умножения — сложение. Тот же приём уже встречался при обсуждении оценки максимального правдоподобия в курсе машинного обучения.

На пальцах

Витерби — «лучший маршрут с хлебными крошками»: в каждой клетке решётки храним не сумму весов всех маршрутов, а вес лучшего маршрута сюда ($\delta$) и указатель, откуда он пришёл ($\psi$). Дойдя до последнего столбца, выбираем лучшую клетку и по указателям возвращаемся к старту — это и есть backtracking.

Почему «по точкам» не работает — конкретный контрпример, найденный численно (три состояния, два символа, $T=4$): $A=\begin{pmatrix}0{,}91 & 0{,}09 & 0\\ 0 & 0{,}02 & 0{,}97\\ 0{,}07 & 0{,}92 & 0\end{pmatrix}$, $B$ (столбцы — символы 0 и 1): строки $(0{,}40;\,0{,}60)$, $(0{,}67;\,0{,}33)$, $(0{,}97;\,0{,}03)$, $\pi_0=(0{,}30;\,0{,}65;\,0{,}05)$, наблюдения $(0,1,0,0)$. Поточечные максимумы $\gamma$ дают путь $(1,1,3,2)$, но переход $1\to3$ имеет $a_{13}=0$ — такой путь имеет нулевую вероятность. Витерби даёт $(1,1,1,1)$. Каждое $\gamma_t$ по отдельности честное, но «сшитые» из них состояния не обязаны образовывать возможную траекторию.

Вне слайдов

Формально: $\arg\max_i\gamma_t(i)$ максимизирует маргинальные вероятности $P(Z_t=i\mid X)$ по отдельности (минимизирует ожидаемое число ошибок по позициям), а Витерби максимизирует совместную $P(Z_{1:T}\mid X)$. Даже когда путь MAP-по-точкам допустим, он может отличаться от Витерби; для разметки последовательностей (режимы, удары ЭКГ) используют Витерби, для «уверенности в режиме на день $t$» — $\gamma_t$ (как на сл. 19). В hmmlearn: decode()/predict() — Витерби (по умолчанию algorithm='viterbi'), predict_proba() — $\gamma_t$.

4.4. Задача 3: Баум–Уэлш — E-шаг (сл. 13)

EM-алгоритм для HMM. Скрытые переменные: $Z_{1:T}$. Параметры: $\lambda=(A,B,\pi_0)$. E-шаг: вычислить апостериорные вероятности при $\lambda^{\text{old}}$: $\gamma_t(i)$ — как выше; апостериорная вероятность совместного перехода $$\xi_t(i,j)=P(Z_t=s_i,Z_{t+1}=s_j\mid X_{1:T},\lambda)=\frac{\alpha_t(i)\,a_{ij}\,b_j(X_{t+1})\,\beta_{t+1}(j)}{\sum_{i',j'}\alpha_t(i')\,a_{i'j'}\,b_{j'}(X_{t+1})\,\beta_{t+1}(j')}.$$ Интерпретация: $\xi_t(i,j)$ — ожидаемое число «использований» перехода $i\to j$ в момент $t$ при данных наблюдениях (сл. 13).

Из записи лекции [59:16–1:05:20]

Задача обучения: дана последовательность наблюдений, параметры $\lambda$ неизвестны — их надо найти. Это максимизация правдоподобия при скрытых переменных; для неё создан EM-алгоритм. Скрытые переменные — последовательность состояний $Z_{1:T}$, наблюдения — $X_{1:T}$. Алгоритм состоит из двух шагов. E-шаг: при фиксированных текущих параметрах $\lambda^{\text{old}}$ (в начале их задают как-то — случайно, нулями-единицами, как в любом итеративном алгоритме) вычисляем апостериорные вероятности — $\gamma$ по формуле сл. 11 и ещё одну величину, $\xi_t(i,j)$: вероятность того, что в момент $t$ система была в состоянии $i$, а в момент $t+1$ — в состоянии $j$, при условии наблюдений и текущих параметров. В числителе — произведение прямой переменной, вероятности перехода, вероятности эмиссии следующего наблюдения и обратной переменной; в знаменателе — нормировка. Интерпретация: ожидаемое число использований перехода $i\to j$ на шаге $t$ при данной выборке.

На пальцах

EM — «курица и яйцо»: если бы мы знали скрытые состояния, оценить $A$ и $B$ было бы просто (посчитать частоты); если бы знали $A$ и $B$, то нашли бы состояния (forward-backward). Не зная ни того, ни другого, чередуем: по текущим параметрам считаем «мягкие» метки $\gamma$ и $\xi$ (не «состояние равно $i$», а «состояние равно $i$ с вероятностью 0,8»), по ним переоцениваем параметры, и так до сходимости. $\xi_t(i,j)$ — мягкий счётчик: «на этом шаге переход $i\to j$ был использован на 0,3».

4.5. Баум–Уэлш — M-шаг и гарантия сходимости (сл. 14)

M-шаг: максимизировать $Q(\lambda,\lambda^{\text{old}})=\mathbb{E}_{Z\mid X,\lambda^{\text{old}}}\big[\log P(X,Z\mid\lambda)\big]$. Переоценка в замкнутом виде: $$\hat\pi_{0,i}=\gamma_1(i),\qquad \hat a_{ij}=\frac{\sum_{t=1}^{T-1}\xi_t(i,j)}{\sum_{t=1}^{T-1}\gamma_t(i)},\qquad \hat b_j(k)=\frac{\sum_{t:\,X_t=v_k}\gamma_t(j)}{\sum_{t=1}^{T}\gamma_t(j)}.$$ Гарантия сходимости EM: $P(X_{1:T}\mid\hat\lambda)\ge P(X_{1:T}\mid\lambda^{\text{old}})$ на каждой итерации. Сходится к локальному максимуму или седловой точке. Критерий остановки: $|\log P(X\mid\lambda^{(k+1)})-\log P(X\mid\lambda^{(k)})|\lt\varepsilon$ (сл. 14).

Из записи лекции [1:05:20–1:09:00]

M-шаг максимизирует ожидаемое полное логарифмическое правдоподобие по параметрам, и получается «красивый замкнутый результат»: новая оценка $a_{ij}$ — ожидаемое число переходов из $i$ в $j$, делённое на ожидаемое число всех переходов из $i$ куда бы то ни было; оценка эмиссии — ожидаемая доля времени, когда система в состоянии $j$ и наблюдается символ $k$, делённая на нормировку. Интуиция: это частоты, как в обычном оценивании методом максимального правдоподобия, только взвешенные апостериорными вероятностями.

Главное, что даёт EM, — правдоподобие не убывает от итерации к итерации; это математический факт и, по сути, гарантия сходимости. Цена: сойдётся, но не гарантированно к глобальному оптимуму — может к локальному или к седловой точке. (В записи лектор говорит «локальному минимуму», а в ответах на вопросы поправляет себя: максимуму, поскольку правдоподобие максимизируется.) Для борьбы с этим используют рестарты — о них позже.

На пальцах

Формулы M-шага — это «частоты по мягким меткам»: если бы метки были жёсткими, $\hat a_{ij}$ была бы просто «сколько раз после $i$ шло $j$» делить на «сколько раз было $i$». С мягкими метками вместо единиц складываем вероятности. Гарантия «не хуже, чем на прошлой итерации» означает, что кривая $\log P(X\mid\lambda^{(k)})$ монотонно растёт и выходит на плато — по этому плато и останавливаемся ($\varepsilon$). Но плато может быть «холмом в долине» (локальный максимум), а не вершиной — отсюда рестарты с разных стартовых точек.

Вне слайдов

Почему правдоподобие не убывает: $\log P(X\mid\lambda)=Q(\lambda,\lambda^{\text{old}})+H(\lambda,\lambda^{\text{old}})$, где $H$ — энтропийный член, который по неравенству Йенсена минимален при $\lambda=\lambda^{\text{old}}$; увеличивая $Q$ на M-шаге, увеличиваем и $\log P$. Для $\hat\pi_0$ при одной последовательности оценка $\gamma_1(i)$ опирается на единственное наблюдение — параметр плохо идентифицируем; в hmmlearn его можно не обучать, убрав 's' из params. Практический критерий остановки в hmmlearn — tol по приросту логарифма правдоподобия и n_iter; история сходимости — в model.monitor_.

4.6. Gaussian HMM для непрерывных наблюдений (сл. 15)

Эмиссионное распределение: $$b_j(x)=\mathcal{N}(x;\mu_j,\sigma_j^2)=\frac{1}{\sigma_j\sqrt{2\pi}}\exp\!\Big(-\frac{(x-\mu_j)^2}{2\sigma_j^2}\Big).$$ Переоценка на M-шаге: $$\hat\mu_j=\frac{\sum_t\gamma_t(j)\,x_t}{\sum_t\gamma_t(j)},\qquad \hat\sigma_j^2=\frac{\sum_t\gamma_t(j)\,(x_t-\hat\mu_j)^2}{\sum_t\gamma_t(j)}.$$ Обобщения: GMM-эмиссии $\sum_m w_{jm}\mathcal{N}(\mu_{jm},\Sigma_{jm})$ — для мультимодальных состояний; многомерный случай $b_j(\mathbf{x})=\mathcal{N}(\mathbf{x};\boldsymbol\mu_j,\Sigma_j)$, M-шаг аналогичен. На практике: GaussianHMM(n_components=N, covariance_type='full') из hmmlearn (сл. 15).

Из записи лекции [1:09:00–1:14:03]

Указание к лабораторной: наблюдения будут непрерывными — по номеру варианта либо доходности, либо признаки из ЭКГ; дискретной матрицы эмиссий $B$ для этого недостаточно. Самое естественное решение — гауссовские эмиссии: каждое скрытое состояние порождает наблюдение из нормального распределения со своими средним и дисперсией. На M-шаге для гауссовских параметров получаются взвешенное среднее и взвешенная дисперсия с весами $\gamma_t(j)$: если в момент $t$ мы почти уверены, что система в состоянии $j$, наблюдение $x_t$ сильно влияет на оценку среднего этого состояния. Обобщения: GMM-эмиссии — смесь гауссиан для мультимодальных состояний; многомерный случай — полная ковариационная матрица $\Sigma$ для векторных наблюдений. В Python — библиотека hmmlearn, которую предполагается использовать в лабораторной; нужен класс GaussianHMM.

На пальцах

Вместо таблицы «состояние → вероятность символа» у каждого состояния своя «колокольная кривая»: спокойный рынок — узкая, около нуля; бурный — широкая. $b_j(x)$ — высота кривой состояния $j$ в точке наблюдения $x$: чем выше, тем «правдоподобнее» это наблюдение в этом состоянии. Переоценка среднего — взвешенное среднее всех наблюдений, где вес — «насколько мы верим, что в этот момент было состояние $j$». Многомерный случай для ЭКГ: наблюдение — пара (RR-интервал, амплитуда), «колокол» становится холмом на плоскости, а его горизонтали — эллипсами, как на сл. 20.

Вне слайдов (hmmlearn 0.3.3, проверено в песочнице)

Сигнатура: GaussianHMM(n_components=1, covariance_type='diag', min_covar=0.001, ..., algorithm='viterbi', random_state=None, n_iter=10, tol=0.01, params='stmc', init_params='stmc', implementation='log'). Значение по умолчанию covariance_type='diag' — для двумерных признаков ЭКГ лектор рекомендует 'full'. n_iter=10 по умолчанию мало — для ЛР ставить 100–500 и контролировать сходимость по monitor_.converged. Средние инициализируются k-means (в _init используется sklearn.cluster.KMeans), поэтому разные random_state дают разные старты — механизм рестартов. min_covar добавляется к дисперсиям и защищает от вырождения ковариаций (сингулярность при «схлопывании» состояния на одну точку). Методы: fit, score (логарифм правдоподобия), decode/predict (Витерби), predict_proba ($\gamma_t$), sample, bic, aic. После обучения — startprob_, transmat_, means_, covars_.

4.7. Выбор числа состояний и численные ловушки (сл. 16)

Выбор $N$. BIC: $-2\log P(X\mid\hat\lambda)+k\log T$, где $k=N^2-N+2NM-N$ (число свободных параметров). AIC: $-2\log P(X\mid\hat\lambda)+2k$ — мягче. Интерпретируемость: при $N\gt4$ состояния теряют смысл в большинстве задач (сл. 16).

Численные ловушки (сл. 16):

  1. Underflow: работать в log-пространстве или нормировать $\alpha_t$ на каждом шаге.
  2. Вырождение: одно состояние поглощает все точки. Причина: плохая инициализация. Решение: K-means + несколько рестартов.
  3. Локальные максимумы: EM не гарантирует глобальный оптимум. Запускать 10–20 рестартов, выбирать по $\log P(X\mid\hat\lambda)$.
  4. Перекрытие: $\hat\mu_i\approx\hat\mu_j$ — уменьшить $N$.
Из записи лекции [1:14:03–1:24:37]

Выбор $N$. Скрытые состояния мы не видим, поэтому $N$ — гиперпараметр, как в машинном обучении. Метода, который на основе теоретических выкладок однозначно отвечал бы, сколько состояний нужно, нет; на практике два инструмента — BIC и AIC. BIC: минус два логарифма правдоподобия плюс штраф за сложность, пропорциональный логарифму длины ряда $T$; чем больше состояний, тем лучше правдоподобие, но сильнее штраф (в $k$ входит $N$); ищем минимум критерия. AIC — очень похожая формула с более мягким штрафом. Интерпретация: при $N\gt4$ скрытые состояния в прикладных задачах обычно теряют физический смысл, их невозможно интерпретировать; но в конкретных предметных областях 4–6 и более состояний могут быть оправданы — исходить из задачи.

Underflow. Произведение тысячи вероятностей — порядка $10^{-1000}$; машинное округление даёт ноль. Решение простое: работать в логарифмическом пространстве либо нормировать $\alpha_t$ на каждом шаге. Аналогия с переполнением (overflow): в один байт помещаются числа 0–255, и $100+200=300$ туда не записать — теряются разряды; underflow — противоположная проблема, не хватает точности записать слишком маленькое число («в русском языке нет слова недополнение»).

Вырождение. Одно состояние забирает все точки выборки: апостериорная $\gamma$ для него близка к единице на всех шагах; в обученной модели одно состояние доминирует, остальные встречаются крайне редко. Причина — неудачная инициализация; решение — несколько рестартов и, как вариант, алгоритм k-средних для поиска более удачных начальных состояний.

Локальные максимумы. EM не гарантирует глобальный оптимум; чтобы не застрять, делают несколько рестартов — «обычно рекомендуют до 20», — а из 20 полученных моделей выбирают наилучшую по финальному правдоподобию.

Перекрытие. Два скрытых состояния накладываются друг на друга — среднее одного близко к среднему другого; бороться уменьшением $N$, выбранного по BIC/AIC.

На пальцах

BIC — «налог на параметры»: каждое дополнительное состояние дарит модели свободу подогнаться под данные (правдоподобие растёт всегда), и критерий требует, чтобы выигрыш окупал «налог» $k\log T$. AIC берёт налог поменьше ($2k$), поэтому чаще выбирает более сложную модель. Правило $N\le4$ — про здравый смысл: пять «режимов рынка» или шесть «ритмов сердца» обычно уже некому объяснить.

Вырождение выглядит так: обучили три состояния, а Витерби красит 99 % точек одним цветом, у остальных состояний дисперсия либо огромная, либо схлопнулась. Перекрытие — два состояния с почти одинаковыми $\hat\mu$ и $\hat\sigma$: модель «поделила один режим пополам». Рестарты — запуск EM с разных случайных стартов (разные random_state); сравнивать модели надо по одному и тому же критерию — $\log P(X\mid\hat\lambda)$ на тех же данных.

Вне слайдов: проверка формулы для $k$

Стандартный подсчёт свободных параметров Gaussian HMM с $M$-мерными наблюдениями: начальное распределение $N-1$; матрица переходов $N(N-1)$; средние $NM$; дисперсии $NM$ (диагональные) или $N\cdot M(M+1)/2$ (полные ковариации). Для диагонального случая $k=N^2+2NM-1$. Формула слайда $k=N^2-N+2NM-N=N^2+2NM-2N$ даёт меньше: при $N=2$, $M=1$ — 4 против 7; при $N=3$, $M=2$ (полные ковариации) — 15 против 23. Ровно эти же числа (7 и 23) возвращает подсчёт hmmlearn внутри методов bic()/aic() (проверено). Для ранжирования моделей по $N$ разница часто не меняет выбор, но для сопоставимости с библиотекой в ЛР стоит либо использовать model.bic(X), либо явно писать, какой подсчёт $k$ принят. Расхождение — на слайде, в записи формула не комментируется.

§5. Байесовский вывод параметров HMM через MCMC (сл. 17)

Мотивация: Баум–Уэлш даёт $\hat\lambda=\arg\max P(X\mid\lambda)$ — одну точку, неопределённость теряется. Байес — полное апостериорное $P(\lambda\mid X)$. Приоры: $A_i\sim\mathrm{Dir}(\alpha_i)$, $\mu_j\sim\mathcal{N}(\mu_0,\Sigma_0)$; $$P(\lambda,Z_{1:T}\mid X_{1:T})\propto P(X\mid Z,\lambda)\,P(Z\mid\lambda)\,P(\lambda).$$ Blocked Gibbs sampler, итерация: (1) сэмплировать $Z_{1:T}\mid X_{1:T},\lambda$ — через forward-backward + обратная выборка; (2) сэмплировать $\lambda\mid Z_{1:T},X_{1:T}$ — сопряжённые распределения: $A_i\mid Z_{1:T}\sim\mathrm{Dir}(\alpha_i+\{n_{ij}\})$. Даёт: доверительные интервалы для $a_{ij},\mu_j,\sigma_j$; устойчивость к локальным максимумам. Цена: $10^2$–$10^3\times$ медленнее EM. Инструменты: PyMC, Stan, pyhsmm (сл. 17).

Всё до сих пор — максимизация правдоподобия, одна оценка параметров. Иногда этого мало: хочется знать, насколько мы уверены в оценке, скажем, $a_{ij}=0{,}3$ — могла ли она быть $0{,}1$ или $0{,}8$? Байесовский подход: вместо точечной оценки — апостериорное распределение параметров при нашей выборке. Задаём приоры: для строк матрицы переходов — распределение Дирихле («натуральное для векторов вероятностей»), параметры которого интерпретируются как псевдосчётчики переходов; для гауссовских параметров — сопряжённые приоры. Затем сэмплируем из апостериорного распределения. Общий MCMC (Markov chain Monte Carlo) здесь неэффективен; эффективнее блочное сэмплирование Гиббса из двух чередующихся шагов: при фиксированных $\lambda$ сэмплируем последовательность скрытых состояний через прямой-обратный ход и обратный выбор; при фиксированных состояниях сэмплируем параметры. Это даёт доверительные интервалы на любые параметры и устойчивость к локальным максимумам, но алгоритм в сотни и тысячи раз медленнее EM. Библиотеки: PyMC, Stan, pyhsmm. Лектор снова проводит параллель с обучением ограниченной машины Больцмана, где MCMC (в упрощённом виде) тоже используется как алгоритм обучения.

На пальцах

EM отвечает «какое $\lambda$ лучше всего», Байес — «какие $\lambda$ вообще совместимы с данными и насколько». Гиббс — «чередование двух угадываний»: зная правила, разыгрываем правдоподобный путь фишки; зная путь, разыгрываем правдоподобные правила; повторив тысячи раз, получаем облако вариантов правил — из него и берутся интервалы для $a_{ij}$. Дирихле-приор с псевдосчётчиками — «мы как будто уже видели $\alpha_{ij}$ переходов $i\to j$ до начала наблюдений»; это же спасает от нулевых вероятностей при малых данных.

Вне слайдов

«Обратная выборка» на шаге 1 — forward filtering, backward sampling: после прямого хода $z_T$ разыгрывается из $\alpha_T(\cdot)$, затем $z_t$ — из распределения, пропорционального $\alpha_t(i)\,a_{i,z_{t+1}}$. Сопряжённость: при известных $Z$ строки $A$ имеют Дирихле-апостериор с счётчиками переходов $n_{ij}$, а средние/дисперсии гауссиан — нормальный / обратный-гамма (или нормальный-обратный-Уишарта в многомерном случае). Известная ловушка байесовских HMM — переключение меток состояний (label switching) между сэмплами; его снимают упорядочиванием состояний, например по $\mu_j$. В ЛР этот раздел не обязателен — лектор относит его к случаю «нужны интервалы или мало данных» (сл. 21).

На пальцах

Доходность $-1\%$ находится примерно в полутора «сигмах» от центра спокойного режима ($0{,}6$–$0{,}75\%$) и в половине «сигмы» бурного ($2\%$): плотности в этой точке сравнимы, и один день ничего не решает. Зато десять подряд дней с размахом $\pm2\%$ в спокойном режиме почти невероятны — последовательность выдаёт режим. Это и делает forward-backward: перемножает «свидетельства» всех дней с учётом того, что режимы сменяются редко ($a_{ii}$ близко к 1).

На пальцах

$1/(1-a_{ii})$ — среднее число дней до выхода из режима: каждый день с вероятностью $1-a_{ii}$ «выпадает» выход, время до первого выхода геометрическое, его среднее — обратная величина. При $a_{ii}=0{,}97$ выход случается раз в $\approx33$ дня; при $0{,}9$ — раз в 10. Читая матрицу переходов обученной модели, вы сразу видите «типичную длину эпизода» каждого режима — удобная проверка на здравый смысл: режим «кризис» длиной в среднем два дня, скорее всего, ловит шум.

Сигнал. ЭКГ снимается электродами; токи очень слабые, но фиксируются. Стандартная частота дискретизации цифрового кардиографа — порядка 360 Гц; за минуту записи набирается $360\cdot60$ точек — больше, чем накоплено по финансовым данным за 20 с лишним лет. Поэтому на практике работают не с отдельными отсчётами, а с признаками. Структура кардиоцикла — комплекс P-QRS-T: небольшой пик P, впадина Q, большой пик R (основное сокращение сердечной мышцы), впадина S, пик T.

Признаки. Первый — RR-интервал, время между соседними R-пиками: подсчёт R-пиков за минуту даёт пульс — так работают умные часы. Второй — нормализованная амплитуда R-пика: высота пиков тоже случайна, каждое сокращение немного отличается по силе, поэтому амплитуду приводят к диапазону 0–1. Отсутствие ожидаемого пика или пик малой высоты — признак аномалии («я не врач, что именно не так, не скажу, но это аномалия»).

Отступление про стресс. Часы, измеряющие стресс, оценивают на окне дисперсию RR-интервалов: по словам лектора, при стрессе сердце сокращается «как часы», через одинаковые интервалы, а в спокойном состоянии интервалы случайны; строго равные интервалы — плохой признак.

Кластеры. На диаграмме три облака — три состояния гауссовской HMM: синусовый ритм; тахикардия (усиленное сердцебиение — не обязательно болезнь, например нагрузка на беговой дорожке; RR около 450 мс — «минимум два сокращения в секунду, пульс порядка 120»; у синусового ритма RR около 850 мс — пульс 60–70); аномалии — облако диффузное, «аномалии есть практически всегда, и это нормально: сердечная мышца не работает как компьютер, случайность заложена природой». Эллипсы — контуры двумерных гауссиан, на которые опирается модель.

Результат и ограничение. Витерби даёт разметку по ударам; при сравнении с разметкой кардиолога точность до 90 % на качественно аннотированных записях. Ограничение: модель видит только два признака, вся структура P-QRS-T ей не видна; по-хорошему нужны либо $n$-мерные гауссианы с большим числом признаков, либо преобразователь признаков перед HMM — в рамках курса не рассматривается.

Часто синусовый ритм и тахикардия накладываются; на некоторых записях тахикардии нет вовсе — только синусовый ритм и аномалии, кластеров два, а не три. Это вопрос, который должны поднять и решить те, кому достанется ЭКГ: построить модель, визуализировать и посмотреть, какие кластеры получились.

На пальцах

Переход «от отсчётов к ударам» — главный приём: сигнал в 360 Гц превращается в последовательность точек на плоскости (RR, амплитуда), по одной на удар. Синусовый ритм — «правый верхний угол» (длинные интервалы, высокие пики), тахикардия — «левый верх» (короткие интервалы), аномалии — «внизу и размазаны». HMM добавляет к этой картине время: удары не перемешаны, режимы идут эпизодами, и матрица переходов это использует — одиночная «аномальная» точка внутри длинного синусового эпизода может быть отнесена к синусу, если так правдоподобнее для всей последовательности.

Раздел 3. Вопросы для подготовки к защите лабораторных (теория)

Формат ответа: сначала тезис (1–2 предложения), затем аргументация от лица студента; ссылки на слайды и таймкоды — для самопроверки.

1. Почему нельзя искать скрытые состояния просто по максимуму апостериорной вероятности $\arg\max_i\gamma_t(i)$?

Тезис: $\gamma_t(i)$ — маргинальная вероятность состояния в один момент; выбирая максимум в каждый момент по отдельности, мы получаем набор состояний, который может не быть возможной траекторией — например, содержать переход с $a_{ij}=0$. Витерби максимизирует вероятность всей последовательности целиком.

Аргументация: $\gamma_t(i)=\alpha_t(i)\beta_t(i)/\sum_j\alpha_t(j)\beta_t(j)$ учитывает все наблюдения, но суммирует по всем путям, проходящим через $(i,t)$, — она ничего не говорит о согласованности соседних решений (сл. 12; запись 52:07). Численный контрпример из п. 4.3: при $a_{13}=0$ поточечные максимумы дают путь $(1,1,3,2)$ нулевой вероятности, Витерби — $(1,1,1,1)$. Витерби решает $\max_{z_{1:T}}P(z_{1:T},X\mid\lambda)$ по той же решётке, заменив сумму на максимум и запоминая $\psi$ для backtracking; сложность та же $O(N^2T)$. Поточечный MAP уместен, когда нужна именно «уверенность в режиме на день $t$» (раскраска сл. 19), а не разметка траектории.

2. Марковская цепь — это процесс «без памяти»? Как тогда она порождает долгие корреляции?

Тезис: нет; память есть, но вся она сжата в текущем состоянии — это предположение о структуре зависимости, а не о её отсутствии. Долгие корреляции возникают через $A^n$: их затухание определяется вторым собственным числом $A$ и может быть медленным.

Аргументация (сл. 3; запись 08:11): условие $P(X_{t+1}\mid X_{0:t})=P(X_{t+1}\mid X_t)$ означает, что более ранние состояния не добавляют информации сверх текущего, а не что прошлое не влияет. $(A^n)_{ij}$ — вероятность через $n$ шагов; при $\lambda_2=0{,}6$ (матрица рынка) отклонение от $\pi$ убывает как $0{,}6^n$; при $\lambda_2=0{,}99$ память «длинная», хотя цепь марковская. Если $k$ прошлых значений реально нужны, состояние укрупняют до набора последних $k$ значений — цепь порядка $k$ сводится к порядку 1.

3. Почему строки $A^n$ становятся одинаковыми, при каких условиях и что их нарушает?

Тезис: для неприводимой апериодической цепи $A^n\to\mathbf{1}\pi$ — все строки сходятся к стационарному распределению, единственному решению $\pi A=\pi$; нарушают это поглощающие/несущественные состояния (неприводимость) и периодичность (предела нет, сходится лишь среднее Чезаро).

Аргументация (сл. 5–6; запись 19:09–28:42): $\pi$ — левый собственный вектор при $\lambda=1$ (Перрон–Фробениус), $\pi_i=1/\mathbb{E}[T_i]$; в примере рынка $\pi=(0{,}542;\,0{,}292;\,0{,}167)$, строки совпадают уже при $n=10$. Если есть ловушка (отказ, $a_{ii}=1$), вся масса со временем уходит в неё, и «доля времени в рабочем состоянии» теряет смысл — вместо $\pi$ считают MTTF через $(I-Q)^{-1}$. При периоде $d\gt1$ (цепь-«маятник») $A^n$ колеблется.

4. Почему Forward работает за $O(N^2T)$, если путей $N^T$?

Тезис: потому что $\alpha_{t+1}(j)$ зависит от прошлого только через $N$ чисел $\alpha_t(\cdot)$ — марковость и условная независимость позволяют «схлопнуть» все пути в узлах решётки.

Аргументация (сл. 10–11; запись 45:27): $\alpha_{t+1}(j)=b_j(X_{t+1})\sum_i\alpha_t(i)a_{ij}$ — в каждой из $NT$ клеток $N$ операций. Наивно при $N=3$, $T=100$ пришлось бы сложить $3^{100}$ слагаемых. Тот же принцип у Витерби (max вместо суммы) и у Баума–Уэлша (E-шаг — forward-backward). Итог $P(X\mid\lambda)=\sum_i\alpha_T(i)$ — сумма последнего столбца.

5. Что такое underflow в HMM и как с ним бороться? Почему log-space не портит ответ?

Тезис: $\alpha_t$ и $\delta_t$ — произведения сотен вероятностей, порядка $10^{-100}$ и меньше, и округляются в машинный ноль; логарифмирование превращает произведения в суммы, а максимум и сумма в log-space считаются точно (logsumexp), поэтому argmax Витерби и $\log P$ не меняются.

Аргументация (сл. 12, 16; запись 56:35, 1:18:58): $\log\delta_{t+1}(j)=\log b_j+\max_i[\log\delta_t(i)+\log a_{ij}]$; для Forward — $\operatorname{logsumexp}$. Альтернатива — нормировать $\alpha_t$ на каждом шаге и накапливать $\sum\log c_t$. В hmmlearn — implementation='log' (по умолчанию) или 'scaling'. Для Gaussian HMM в log-space удобно и то, что $\log b_j(x)$ — квадратичная функция без экспонент.

6. Что гарантирует EM (Баум–Уэлш), чего не гарантирует, и как выбирать среди рестартов?

Тезис: гарантирует монотонный рост $P(X\mid\lambda^{(k)})$ и сходимость к стационарной точке — локальному максимуму или седлу; не гарантирует глобальный максимум. Поэтому 10–20 запусков с разными инициализациями и выбор модели с наибольшим $\log P(X\mid\hat\lambda)$.

Аргументация (сл. 14, 16; запись 1:07:02, 2:06:23–2:15:04): M-шаг максимизирует $Q(\lambda,\lambda^{\text{old}})$, а $\log P=Q+H$ с минимумом $H$ в $\lambda^{\text{old}}$ — отсюда неубывание. Начальное приближение обязательно (нулями нельзя — строки $A$ должны суммироваться в 1); разные random_state в hmmlearn дают разные k-means-старты. Сравнивать решения нужно по одному критерию на одних данных; для разных $N$ — по BIC, а не по $\log P$ (он растёт с $N$ всегда). Глобальный максимум за конечное время не гарантирует никто — «дихотомия: либо за конечное время, либо максимально точно».

7. Почему в ЛР эмиссии гауссовские и почему одного наблюдения недостаточно, чтобы определить режим?

Тезис: наблюдения (доходности, признаки ударов) непрерывны, дискретная $B$ не подходит — каждому состоянию сопоставляют $\mathcal{N}(\mu_j,\sigma_j^2)$ (или многомерную $\mathcal{N}(\boldsymbol\mu_j,\Sigma_j)$); режимы отличаются в основном шириной распределений и перекрываются, поэтому только последовательность наблюдений (forward-backward) даёт надёжный ответ.

Аргументация (сл. 8, 15, 18; запись 35:07, 1:09:00, 1:32:00): $-1\%$ — «норма» при $\sigma=2\%$ и «тревога» при $0{,}6\%$; плотности двух режимов в этой точке сравнимы. M-шаг для гауссиан — взвешенные по $\gamma_t(j)$ среднее и дисперсия: наблюдение влияет на параметры состояния пропорционально уверенности, что оно из этого состояния. Для двумерных признаков ЭКГ — covariance_type='full', эллипсы гауссиан на диаграмме рассеяния.

8. Как выбрать число состояний $N$? Что такое BIC и почему «при $N\gt4$ — осторожно»?

Тезис: $N$ — гиперпараметр без теоретически «правильного» значения; на практике — минимум BIC (или AIC) плюс интерпретируемость: правдоподобие растёт с $N$ всегда, а критерий штрафует за $k$ параметров; при $N\gt4$ состояния обычно теряют физический смысл.

Аргументация (сл. 16, 21; запись 1:14:03, 2:20:35): $\mathrm{BIC}=-2\log P+k\log T$, штраф растёт с длиной ряда; AIC ($2k$) мягче. Лектор сравнивает с числом кластеров в кластеризации: два режима волатильности достаточны для решения «покупать/продавать»; врачу — два или три ритма в зависимости от опыта и записи. Проверки помимо критерия: нет ли перекрытия ($\hat\mu_i\approx\hat\mu_j$ — уменьшить $N$), правдоподобны ли длительности $1/(1-a_{ii})$. Формула для $k$ на слайде отличается от стандартного подсчёта (п. 4.7) — на защите стоит назвать, какой подсчёт используется.

9. Чем CTMC отличается от дискретной цепи? Что такое генератор $Q$ и коэффициент готовности?

Тезис: в CTMC переходы происходят в произвольные моменты, и вместо вероятностей за шаг задаются интенсивности $q_{ij}$; матрица генератора имеет нулевые суммы строк, эволюция $P(t)=e^{Qt}$, стационарное $\pi Q=0$; для пары «работа/отказ» доля времени в работе $\mu/(\lambda+\mu)$ — коэффициент готовности. Дискретная цепь — «снимок» непрерывной: $A=e^{Q\Delta t}$.

Аргументация (сл. 7; запись 28:42): $P(X_{t+\Delta t}=j\mid X_t=i)=q_{ij}\Delta t+o(\Delta t)$; диагональ $q_{ii}=-\sum_{j\ne i}q_{ij}$ сохраняет массу; прямые уравнения Колмогорова $\dot P=PQ$. Пример: $\lambda=0{,}05$, $\mu=0{,}5$ в час — готовность $0{,}909$ (проверено через $e^{Qt}$). Время пребывания в состоянии экспоненциально с параметром $-q_{ii}$.

10. Что такое MTTF и как его посчитать по матрице переходов?

Тезис: MTTF — среднее число шагов (или время) до первого попадания в поглощающее состояние «отказ»; считается через фундаментальную матрицу $(I-Q)^{-1}$, где $Q$ — подматрица переходов между несущественными (рабочими) состояниями: $\mathrm{MTTF}=e_0^{\top}(I-Q)^{-1}\mathbf{1}$.

Аргументация (сл. 6; запись 25:00–28:42): $(I-Q)^{-1}=\sum_{n\ge0}Q^n$ — ожидаемое число посещений каждого рабочего состояния до поглощения; сумма строки стартового состояния — ожидаемая длина пути. Пример из п. 1.5: $p_1=0{,}1$, $p_3=0{,}01$, $r=0{,}3$, $p_2=0{,}2$ дают 24 шага из «Раб», что совпадает с симуляцией. Поглощающее состояние нарушает эргодичность — стационарное распределение вырождается, поэтому MTTF заменяет $\pi$ как основная характеристика надёжности.

11. Зачем байесовский подход и Gibbs sampler, если есть EM? Что он даёт и чего стоит?

Тезис: EM даёт одну точку $\hat\lambda$ без меры неопределённости; байесовский вывод — апостериорное распределение $P(\lambda\mid X)$, то есть интервалы для $a_{ij},\mu_j,\sigma_j$ и устойчивость к локальным максимумам; цена — сэмплирование в $10^2$–$10^3$ раз медленнее EM.

Аргументация (сл. 17; запись 1:24:37): приоры — Дирихле для строк $A$ (параметры — псевдосчётчики переходов), сопряжённые для гауссиан; blocked Gibbs чередует «сэмплировать $Z\mid X,\lambda$ через forward-backward + обратную выборку» и «сэмплировать $\lambda\mid Z,X$ из сопряжённых распределений» ($A_i\mid Z\sim\mathrm{Dir}(\alpha_i+\{n_{ij}\})$). Показан к применению при малых данных или когда нужны доверительные интервалы (сл. 21); инструменты — PyMC, Stan, pyhsmm. В ЛР не обязателен.

12. Откуда берётся «средняя длительность режима $1/(1-a_{ii})$» и как ею проверять модель?

Тезис: время пребывания в состоянии $i$ распределено геометрически — каждый шаг с вероятностью $1-a_{ii}$ происходит выход, среднее число шагов до выхода равно $1/(1-a_{ii})$; это быстрая проверка интерпретируемости обученной модели.

Аргументация (сл. 19; запись 1:40:31): при $a_{11}=0{,}97$ спокойный режим длится в среднем $33$ дня; если у обученной модели «кризисный» режим держится 1–2 дня, он, скорее всего, ловит выбросы, а не режим — сигнал уменьшить $N$ или проверить инициализацию. В синтетическом примере п. 4.5 истинные $0{,}97/0{,}90$ восстановились как $0{,}973/0{,}916$ — длительности $37$ и $12$ дней.

4.4. Ловушки, которые стоит проверить перед защитой

  • Underflow — если пишете Forward/Витерби сами, только log-space или масштабирование; сверьте свой $\log P$ с model.score(X) (в п. 4.5 совпадение до $10^{-4}$).
  • Вырождение — состояние с $\gamma\approx1$ на всём ряду или с дисперсией, схлопнувшейся к min_covar; лечится рестартами/k-means, при необходимости — уменьшением $N$.
  • Перекрытие — два состояния с почти одинаковыми $\hat\mu,\hat\sigma$; уменьшить $N$.
  • Label switching — состояния между запусками нумеруются по-разному; сопоставлять по $\hat\sigma$ (волатильность) или $\hat\mu$ (RR) перед сравнением с разметкой.
  • Сравнение по неверному критерию — рестарты при одном $N$ сравнивать по $\log P$; разные $N$ — по BIC/AIC, не по $\log P$.
  • Недостаток итераций — n_iter=10 по умолчанию; проверять monitor_.converged.

import numpy as np
from scipy.special import logsumexp
from scipy.stats import norm
from hmmlearn.hmm import GaussianHMM

# ---------- 1. Синтетический ряд "доходностей" с двумя режимами волатильности ----------
rng = np.random.default_rng(0)
A_true = np.array([[0.97, 0.03], [0.10, 0.90]])        # a_ii близки к 1: режимы длятся ~33 и ~10 дней
mu_true, sd_true = np.array([0.05, -0.10]), np.array([0.6, 2.0])
T = 1500
z = np.zeros(T, int)
for t in range(1, T):
    z[t] = rng.choice(2, p=A_true[z[t - 1]])
X = rng.normal(mu_true[z], sd_true[z])[:, None]        # hmmlearn ждёт форму (T, n_features)

# ---------- 2. Forward и Витерби "с нуля" в log-space (сл. 11-12) ----------
def log_forward(logpi, logA, logB):
    """logB[t, j] = log b_j(x_t). Возвращает log alpha (T x N) и log P(X | lambda)."""
    T, N = logB.shape
    la = np.empty((T, N)); la[0] = logpi + logB[0]
    for t in range(1, T):                              # alpha_{t+1}(j) = b_j(x_{t+1}) * sum_i alpha_t(i) a_ij
        la[t] = logB[t] + logsumexp(la[t - 1][:, None] + logA, axis=0)
    return la, logsumexp(la[-1])                       # P(X|lambda) = sum_i alpha_T(i)

def log_viterbi(logpi, logA, logB):
    """delta/psi в log-space + backtracking. Возвращает путь и log P лучшего пути."""
    T, N = logB.shape
    ld = np.empty((T, N)); psi = np.zeros((T, N), int); ld[0] = logpi + logB[0]
    for t in range(1, T):
        cand = ld[t - 1][:, None] + logA               # cand[i, j] = log delta_t(i) + log a_ij
        psi[t] = cand.argmax(0); ld[t] = logB[t] + cand.max(0)
    path = np.empty(T, int); path[-1] = ld[-1].argmax()
    for t in range(T - 2, -1, -1):                     # backtracking
        path[t] = psi[t + 1, path[t + 1]]
    return path, ld[-1].max()

def fit_best(X, N, n_restarts=10, n_iter=200):
    """10-20 рестартов с разными random_state (k-means-инициализация средних), лучший по log P."""
    best = None
    for seed in range(n_restarts):
        m = GaussianHMM(n_components=N, covariance_type="full", n_iter=n_iter, tol=1e-4,
                        random_state=seed, implementation="log").fit(X)   # log-space против underflow
        if not m.monitor_.converged:
            print(f"  N={N} seed={seed}: не сошёлся за {n_iter} итераций")
        if best is None or m.score(X) > best.score(X):
            best = m
    return best

models = {N: fit_best(X, N) for N in (1, 2, 3, 4)}
for N, m in models.items():
    print(f"N={N}: logL={m.score(X):9.2f}  BIC={m.bic(X):9.2f}  AIC={m.aic(X):9.2f}")
