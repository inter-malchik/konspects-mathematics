# Конспекты курсов

Статический сайт: две папки HTML-конспектов и главная страница со ссылками.

- `sovpn/` — Современные архитектуры НС
- `time_series/` — Случайные процессы и временные ряды

Локально: открыть `index.html` в браузере.

Хостинг на Render описан в чате / ниже: Static Site, publish directory `.`, без сборки.
